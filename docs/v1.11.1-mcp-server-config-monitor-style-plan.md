# v1.11.1 计划稿 — MCP Server 配置页改造：Monitor Targets 风格 + 弹窗编辑，去掉 Bind Agents

> 本文为改前计划存档（仓库内留档）。执行结果与验证见 `changelogs/v1.11.1-mcp-server-config-monitor-style.md`。

## Context
SIP UI（`service-intelligence-platform-ui`，分支 `master`）的 **MCP Server 配置**页（`#page-mcp-servers`）
目前是「左：内联配置表单 + 已保存列表 / 右：Tools 结果栏」的两栏布局，页面内含一段 **Bind Agents**（勾选绑定 agent）的编辑 UI。

用户要求：
1. 页面风格改成 **Monitor Targets** 那样：顶部是已配置 MCP Server 的**列表**，点 **New** 弹出一个**弹窗**录入/编辑 server 信息（含测试连接），表单字段沿用现有能力。
2. **去掉 Bind Agents** 内容。经确认：后续 agent 绑定将以 **agent 为主表**建模，MCP server 不再是绑定主表，因此本页不再提供按 server 勾选 agent，更新时也不再保留该列的绑定语义。

只改前端三个文件，不动后端。

## 改动文件
- `service-intelligence-platform-ui/index.html`
- `service-intelligence-platform-ui/js/app.js`
- `service-intelligence-platform-ui/css/styles.css`

## 目标交互（对齐 Monitor Targets）
**列表页 `#page-mcp-servers`**：
- 保留 breadcrumb / 标题 / 右上 Refresh。
- 标题副文案去掉 "bind to agents" 措辞。
- `reflow-filter-bar`：搜索框 `#mcpSearch` + 右侧 `New` 按钮（`#mcpNewBtn`，btn-primary）。
- `table-container` + 加载遮罩 `#mcpLoadingOverlay` + `table.reflow-table`：
  列 = **Server Name | Transport | Tools | Enabled | Created | Actions**（Edit / Test / Delete）。
- 底部 pagination 行：`Total N servers` + 提示 "Edit / Test / Delete"。

**弹窗 `#mcpModalOverlay`**（Monitor Target modal 风格：`.ap-modal-overlay/.ap-modal` + header title/hint + close）：
- 字段：Server Name *（含 mcp__{name}__ 前缀提示）、Transport *（stdio/http）、
  `#mcpFieldsStdio`（Command */Args 每行一个/CWD）、`#mcpFieldsHttp`（URL */Headers JSON/Stateful 勾选）、
  `#mcpEnabled` 勾选、`#mcpEnableTools`、`#mcpDisableTools`（白/黑名单逗号分隔）。
- 底部按钮 `apm-form-actions`：Save Server(primary) / 测试连接(secondary) / Reset(outline)。
- `#mcpError` 错误区 + 底部 `details#mcpResult`「测试连接 · Tools 探测」结果区（含 `#mcpResultMeta`、`#mcpResultBody`）。
- 关闭：× / 点遮罩 / Esc。切换 transport 时联动 stdio/http 卡片显隐并清空上次探测结果。

**行动作**：Edit = 打开弹窗回填（先展示已存 tools 快照）；Test = 打开弹窗回填后走 `GET /{mid}/tools`
实时探测并回写；Delete = confirm 后 `DELETE`。工具卡片展示沿用现 `.mcp-tool-*`（只读 ALLOW/非只读 DENY 徽章 + LLM 名）。

## 实现要点
### index.html
整段替换 `<!-- ====== MCP Server 配置 Page ====== -->` 至 `</div><!-- /#page-mcp-servers -->`（当前约
L1552–1662）为：新列表页 markup + 紧随其后的弹窗 markup。**Bind Agents 整块移除**；删掉旧 `#mcpAgents`
容器。保留既有字段 id：`mcpName/mcpTransport/mcpFieldsStdio/mcpStdioCommand/mcpStdioArgs/mcpStdioCwd/
mcpFieldsHttp/mcpHttpUrl/mcpHttpHeaders/mcpHttpStateful/mcpEnabled/mcpEnableTools/mcpDisableTools/
mcpTestBtn/mcpSaveBtn/mcpError/mcpRefreshBtn`；新增：`mcpSearch/mcpNewBtn/mcpLoadingOverlay/mcpTableBody/
mcpRowCount/mcpModalOverlay/mcpFormTitle/mcpFormHint/mcpModalClose/mcpResetBtn/mcpResult/mcpResultMeta/mcpResultBody`。

### js/app.js
重写 `initMcpServers()`（当前约 L5993–6435）为弹窗+表格版：
- 复用现有工具函数思路：`splitList/readConfig/toolLists/stateful()/transport()/setTransportUi/toolItemHtml`。
- `buildBody()` **不再携带 `agents` 字段**（后端 `_to_row` 缺省 `[]` → 更新即清空旧绑定，符合 agent 主表方向）；
  保留 `tools: currentTools`（live 探测成功→随保存落快照；null→create 自动探测/update 保留已存快照）。
- `testConnection()`：`POST /mcp-servers/test`，结果渲染进 `#mcpResultBody`（capture=true → `currentTools`）。
- 表格渲染 `renderList()`：行内嵌 Edit/Test/Delete；空态/搜索过滤用 `#mcpSearch`（按 name/transport）。
- `loadServers()`：`GET /mcp-servers`（列表已含全量 config/tools/agents），带 loading overlay + `_showToast` 错误。
- Edit/Test/Delete handler 委托在 `#mcpTableBody`（Monitor Targets 同款做法）。
- 保留 `_pageRefreshers['page-mcp-servers']` = `loadServers`；Init 末尾 `initMcpServers()` 调用不变。
- 移除 `loadAgentOptions/renderAgentOptions/selectedAgents` 及 `AGENTS_API_BASE`、`agentNames`。
