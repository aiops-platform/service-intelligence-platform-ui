================================

  Section A: Alert Overview（告警概览）
  Section B: Agent Execution Flow（Agent 执行流程）
  Section C: Analysis Report（分析报告，调用 renderAnalysisResult()）

============================================================
完整渲染条件总结
============================================================

Section A (Alert Overview):
  - 始终渲染: severity, status, alertType 标签
  - 条件渲染: sourceFile/gitCommit/fingerprint → error-detail-grid
  - 条件渲染: errorMessage → error-msg-block
  - 条件渲染: stackTrace → stack-block
  - 条件渲染: summary → Description

Section B (Agent Execution Flow):
  - 始终渲染: Invocation meta (agent, model, latency, tokens, status)
  - 条件渲染: thinkingChain > 0 → InvestigationSummary + 可折叠步骤卡片
  - 条件渲染: thinkingChain == 0 → "No thinking chain data available"

Section C (Analysis Report):
  - 条件渲染: analysisResult 存在 → renderAnalysisResult()
      C1 Executive Summary:
        - 条件: risk_level | root_cause | recommendations 任一存在
          - 条件: risk_level → risk badge
          - 条件: confidence → confidence badge
          - 条件: risk_reason | confidence_reason → banner reason
          - 条件: rootCause.type | rootCause.summary → Root Cause 卡片
          - 条件: recommendations 任一非空 → 建议卡片(红色/黄色/绿色)
          - 条件: kb_match → KB Match 行
      C2 Evidence & Analysis:
        - 条件: diagnosisChain|errorSnapshot|codeAnalysis|impactAssessment
          - 条件: diagnosisChain.length > 0 → 步骤卡片
          - 条件: errorSnapshot 有值 → Error Snapshot 网格
          - 条件: codeAnalysis 有值 → Code Traceability + APIs + Changes
          - 条件: impactAssessment 有值 → Impact Assessment
  - 条件渲染: rawOutput (无 analysisResult) → raw text
  - 条件渲染: 都无 → "no output captured"
  - 兜底: 无任何已知字段 → raw JSON dump
