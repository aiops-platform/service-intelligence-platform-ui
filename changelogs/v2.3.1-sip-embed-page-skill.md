## 改动明细

### 1. `.claude/skills/sip-embed-page/SKILL.md`（新增）

8 步流程：判断内嵌还是 Vue 重写 → 侦察 → `PAGES` 加条目 → `--refresh` 拉外壳 →
扫写死文案补 `tenant_copy.py` → Vue 接线（含同名域三处成对）→ **全量重建** →
自检 + 人眼确认 + 文档/changelog。末尾是「坑位速查」表与「不确定时读哪几处」。

判据与坑位都是**本次实际踩到的**，不是复述文档：

- 别拿 Chrome「网页，完整」保存的 html 当入口（那是 DOM 快照，React 不启动）；
- 目录索引的产出路径必须与内层面板表 `route` 逐字相同，否则内层 h1 **静默**变成 `SIP`；
- 同名域（Vue 路由 = 内嵌页路径）要三处成对，少一处就是「硬刷新后没有导航」；
- `public/_next/` 与 `__SIPCOPY__` 四页共用，只重建一页会让另外几页的租户表过期；
- headless 下 WebGL 页（constellation）会渲染成 Next 自己的错误页 —— **别据此判断改坏了**，
  先拿 HEAD 版对照（本次就误判过一次）。

### 2. `.claude/skills/sip-embed-page/scripts/check-embed-wiring.py`（新增）

把「少一处就静默失败」的几条机械校验一遍，有 ✗ 时非零退出，可直接当闸门：

| 检查 | 抓的是 |
|---|---|
| 产出路径 ↔ 内层面板表 `route` | 内层 h1 静默变 `SIP` |
| 同名域时 `EMBED_PAGES` / nginx / 路由登记三处 | 硬刷新拿到裸内嵌页 |
| 有没有视图在渲染它（按视图里出现的入口路径反查） | 页面接不进来 / 域还是空壳 |
| 页面独有 chunk 里「带数字 + 房地产名词」的文案，剔除已被 `LEGACY` 覆盖的 | 切租户时标题与 KPI 各说各话 |
| 各页租户表 vs bundle 租户清单 | 只重建了一页 |

两处设计取舍是**被误报逼出来的**，写在代码注释里：
按「route 的 basename 在不在 `DOMAIN_COMPONENTS`」判会误报 business-ops（域 key 是
`biz-ops`）与 service-ops（走 `STANDALONE_PAGES`）；只认 `<NextEmbed src="/x/">` 字面量会
误报 `ServiceOpsView`（它是 `:src="src"` 绑定，要拼 `?portfolio=`）。现在按**视图里出现的
入口路径**反查，两种写法都覆盖。
