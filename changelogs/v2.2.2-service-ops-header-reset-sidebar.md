# v2.2.2 — 点顶栏 Service Ops 回到概览页并收起侧边栏

**日期**: 2026-09-17

**需求**: 点顶栏的 **Service Ops** 域 → 直接展示概览页，**侧边栏隐藏**。

---

## 背景：概览页本来就到得了，缺的是「收起」

改造后的 `selectDomain()`（`App.vue`）对**有侧边栏的域**落 `/${item.landing}`，
Service Ops 的 `landing` 就是 `service-ops` —— 所以「落到概览页」这一半**早就是对的**。

真正不成立的是后半句。`collapsed` 是 App 实例上的 `ref`，而 App 全局只挂载一次
（`main.js`），`router.push` 不重挂 —— 这是 `v2.0.0-vue-sidebar-collapse` 里**刻意**选的语义
（「SPA 内切页天然保留」）。于是：

| 操作序列 | 改动前的实际结果 | 期望 |
|---|---|---|
| 展开侧边栏 → 点叶子 `/metrics-analysis` | 保持展开 | 保持展开（既有设计，正确） |
| ↑ 之后点顶栏 **Service Ops** | 回到概览，但**侧边栏仍展开** | 概览 + 收起 |
| 在 `/service-ops` 展开后点顶栏 **Service Ops** | **毫无反应** | 收起 |

第三行更刺眼：`router.push('/service-ops')` 是**同址导航**，vue-router 按重复导航忽略掉，
连一次路由变更都没有 —— 用户点了一个域，界面上什么都没发生。

根因不是路由，是**「点域」这个动作没有把该域自己的视图状态复位**。

---

## 改动明细

### 1. `src/App.vue` — selectDomain 里复位折叠状态 (line 135)

**原因**: 让「点顶栏域」= 回到该域的初始形态。

```js
  function selectDomain(item) {
+   if (item.collapsible) collapsed.value = true
    // 有侧边栏的域落到它的 landing；空壳域走自己的路由
    router.push(item.sidebar ? `/${item.landing}` : `/${item.key}`)
  }
```

三处刻意的选择：

- **作用域是 `item.collapsible`（被点的那个域），不是「所有域点击」**：今天只有
  Service Ops 开了这个能力，两种写法行为一致；但 `collapsed` 是**全局一份**、
  不按域存，将来若给 eng-ops 也开 `collapsible`，只有绑在 `item.collapsible` 上
  才会「点谁复位谁」。
- **复位写在 `selectDomain`，不是 `watch(route)`**：域内点侧边栏叶子（`/metrics-analysis`）
  **必须**保住展开态 —— 挂到路由 watch 上会让展开后一导航就自己收起来，等于把
  折叠功能废掉。
- **放在 `push` 之前**：同址导航时 `push` 会被忽略，先赋值才保证这一下仍然生效。

### 2. `src/App.vue` — collapsed 的注释补上这个例外 (line 45-48)

**原因**: 原文写的是「SPA 内切页天然保留」，现在多了一条例外，不改注释就是**过期文档**。

```diff
   * 所以 SPA 内切页天然保留、刷新页面自然回到默认收起，不需要 localStorage。
+  *
+  * 唯一的例外是**点顶栏该域本身**：那一下把它复位回 `true`，语义是「回到该域的初始形态」。
+  * 复位点写在 selectDomain 里，不在这里 watch 路由 —— 域内切叶子（点侧边栏）必须保住展开态，
+  * 否则展开后一导航就自己收起来了。
```

| ★ 已在 `/service-ops` 且展开时点顶栏 Service Ops | 收起（同址导航也生效） | 收起 | OK |

## 遗留 / 不在本次范围

- **`collapsed` 仍是全局一份，不按域存**：今天只有一个可折叠域，够用。真要给
  eng-ops / agents 也开 `collapsible`，且希望「各域各记各的展开态」，得把它换成
  `ref(new Map())` 之类的按域结构 —— 本次不预先做（没有消费方的抽象）。
- **点顶栏 Service Ops 不会重置域内叶子的筛选状态**：`/tickets` 等已迁移视图走
  `KeepAlive`，切走再回来筛选条件还在（`App.vue` 里对 `<RouterView>` 的注释说明了
  这是对齐改造前「所有面板常驻 DOM」的行为）。本次只动了侧边栏，没碰它。
