# v2.2.8 — workflow 图改正交折线 + 只显示节点名 + 固定 fit（去掉缩放）

**日期**: 2026-09-20

**需求/背景**: Run Detail 页的 workflow 图观感要求四条 ——

1. 节点**只显示名称**（不要堆其他信息）
2. 连线用**直线或折线**，且**不要穿过节点被遮挡**
3. 连线**清爽整洁、不要斜线**
4. **不需要放大缩小**，fit 模式展示即可

原实现三条都不满足：连线是「源节点底部中心 → 目标节点顶部中心」的**直线**，
跨列时即**斜线**；而节点在边之后绘制，线直接穿到节点背后被遮挡。
页面还带滚轮缩放 / 拖拽平移 / −·+·Fit 三个按钮。

---

## 改动明细

### 1. `src/components/graph/useGraphCanvas.js` — 连线改正交折线 (212)

**原因**: 直线跨列即斜线，且被节点遮挡。

```js
// before：底部中心 → 顶部中心，一条 <line>
const x1 = p1.x + NODE_W / 2, y1 = p1.y + NODE_H
const x2 = p2.x + NODE_W / 2, y2 = p2.y
html += `<line class="${edgeCls}" x1="${x1}" y1="${y1}" x2="${x2}" y2="${y2}" .../>`

// after：正交折线，横向段走**层间空档**（两层之间必然无节点），
//        竖直段挑一条**畅通车道**（见 pickLane）
html += `<path class="${edgeCls}" d="${edgePath(...)}" fill="none" .../>`
```

### 2. `src/components/graph/useGraphCanvas.js` — 新增 `vFree` / `pickLane` (171 / 188)

**原因**: 竖直段必须避开中间层的节点。

- `vFree(x, y1, y2)`：按**真实几何**（x 区间重叠）判断某竖线是否畅通
- `pickLane(...)`：先试目标列本身；不行再从「各节点两侧的列间空档」挑最近的一条；
  兜底走画布外侧

### 3. `src/components/graph/useGraphCanvas.js` — 去掉缩放 (55 / 299)

**原因**: 需求 4。滚轮、拖拽、+/−/Fit 按钮的绑定**全部移除**；
补 `ResizeObserver` 重算 fit —— 只剩一种模式，容器一变宽窄就得重排。

> 只删按钮不删绑定会留下"滚轮还能缩放"的幽灵行为，所以两边一起删。

### 4. `src/components/graph/GraphCanvas.vue` — 移除缩放控件 DOM

**原因**: 同上。`.bs-zoom-controls` 那三颗按钮从模板删掉，对应的 ref 与 opts 也一并删。

### 5. `src/views/runs/RunDetailView.vue` (29, 32) / `src/views/bug-solve/BugSolveView.vue` (47)

**原因**: 需求 1 与 4。

```js
// before
return { cls, label: n.id + (n.agent ? ` (${n.agent})` : '') }
const HINT = '...。Scroll to zoom · drag to pan.'

// after
return { cls, label: n.id }
const HINT = '...。'
```

两页共用同一引擎，所以 Bug Solve 同步生效（同一张 workflow 在两页长得一样）。

## 踩坑记录（**两次回退**）

### 坑 1：把"跨层"一律当成要绕远路

第一版把所有跨层边都出到画布外侧（`x = PAD / 2`），结果长横线贯穿全图、
长竖线贴边，**视觉上拼成一圈圈"框"，比原来的蜘蛛网还乱**。
截图与改动前对比后才确认是自己引入的。

改成"只借目标列旁边的列间通道"后恢复正常。

### 坑 2：判"畅通"不能用**列号**

第二版按"列号相同 ⇒ 同一竖线"判断，**是错的**：

> 每层各自居中排列（`x0 = PAD + (width - layerW) / 2`），
> **列号相同在不同层的 x 并不一样**。

于是判"畅通"的竖线实际从旁边那层的节点中间穿了过去。
**肉眼看那张图是干净的**——写了几何检查器（解析生成的 SVG、逐段与节点矩形做相交测试）
才扫出 **6 处遮挡**。

改成 `vFree()` 按真实 x 区间重叠判断后归零。

> 教训：这类"看着没问题"的几何缺陷，**肉眼不可靠，要写检查器**。
