## 改动明细

### 1. `src/components/graph/useGraphCanvas.js` — 新增（引擎）

`createGraphCanvas` 逐字移植：Kahn 入度剥层 + 防环兜底 + 层内居中、`NODE_W=150` 等常量、
以光标/画布中心为锚点的缩放、拖拽平移、节点点击委托。

两处适配：

- 元素不再 `document.getElementById` 取，改由调用方传 ref（Vue 持有）
- `.bs-stage` 中间层改由**模板显式渲染**。改造前是引擎动态创建 + `insertBefore` ——
  那会挪动 Vue 管理的节点、在 patch 时产生冲突。模板写死后，原来"异常 DOM 回退到旧行为"
  的分支成为死代码，已删。

`.bs-stage` 这一层**不能省**：变换只施加在舞台上、`.bs-zoom` 保持不动充当视口/裁剪面，
内容才会按视口居中，而不是把整块容器推偏/裁掉。

顺带把 `escapeAttr` 补上 `"` 转义 —— 原 `escapeHtml` 不转引号，用在 `data-node="…"`
属性位上是个隐患。

### 2. `src/components/graph/GraphCanvas.vue` — 新增

**硬约束写在注释里：`<svg>` 内必须为空，一个 Vue 插值子节点都不能有。**
图内容由引擎 `innerHTML` 整段重写（连 `<defs>` 的箭头 marker 一起），Vue 若也渲染 svg
子节点，两边会互相覆盖。

`defineExpose({ render, reset })` 供父组件取用。

### 3. `src/views/bug-solve/useBugSolveRun.js` — 新增

改造前闭包里的 11 个变量升为 ref。`canvas` 由组件持有，经 `getCanvas()` 取用。

**轮询从裸 `setInterval` 改为 `usePolling`** —— 顺带修掉"切走本页后仍 2 秒一轮"。

`applyRun` 的自动跟随逻辑原样保留：运行中把右侧详情切到正在跑的节点；用户手动点选后
`autoFollow = false` 停止跟随。

### 4. `src/views/bug-solve/BugSolveView.vue` — 新增

DOM/class 逐字沿用。**待审批卡片与右侧详情改由模板渲染** —— 改造前是 innerHTML 拼串 +
容器事件委托，因此本视图不再需要 `escapeHtml`，也没有 XSS 面。

`nodeStyle` 逐字移植（`statusClass` 映射 + `kind === 'approval'` 追加 `bs-node-approval`）。

### 5. `src/router/index.js` / `src/App.vue`

`VIEW_COMPONENTS` 加 `bug-solve`（`MIGRATED` 集合里 S0 起就有它）。

## 踩坑记录

### 坑 1：解构漏了 `= run`，被解析成块语句

```js
const run = useBugSolveRun({...})
const { workflows, … }   // ← 少了 `= run`
```

`vite build` 报 `Missing initializer in destructuring declaration (33:1)` —— 报错行号指向
中途的某个标识符，根因却在末尾，不好定位。

### 坑 2：`id` 不能随手改掉 —— CSS 里有 ID 选择器

元素改用 ref 后，我把模板里的 `id="bsGraph"` / `id="bsZoomFit"` 等一并去掉了，觉得"反正
引擎不用 id 取元素了"。grep 后发现 **`styles.css:6081` 有 `#bsZoomFit`** —— 它让 Fit 按钮
变宽（`width:auto; padding:0 8px`），区别于方形的 +/−。去掉 id 会**静默丢样式**（按钮还能点，
只是变窄），属于最难发现的那类回归。已把所有 id 补回并与原标记保持一致。

**教训：改用 ref 并不解除对既有 id 的依赖 —— 样式表是另一个消费方。**

### 坑 3：`.bs-canvas-hint` 有第二个实例

测试里 `.bs-canvas-hint` 命中 2 个元素 —— 另一个是 **legacy Problem Center 的 run 弹窗**
（`#pcRunHint`），它复用了 `.bs-*` 样式（探索阶段记录过）。不是 bug，但说明**测试选择器
必须限定作用域**（用 `#page-bug-solve`），否则会误判。

### 坑 4：跨域 POST 需要预检，桩后端没实现

用桩 agentflow（`:8099`，经 `localStorage.bugSolveBaseUrl` 覆盖，避免动真实控制面的数据）
验证时，`POST /run` 一直发不出去、状态卡在 `started`：浏览器对 `Content-Type: application/json`
的跨域 POST 会先发 `OPTIONS` 预检，而桩没实现 `do_OPTIONS`。补上后即通。

> 真实部署不受影响：走 dev proxy / 生产 nginx 时是**同源**，不触发预检。
