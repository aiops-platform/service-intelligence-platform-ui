# v1.8.0 — 新增 Agent Fleet（Agent Registry）页面

**日期**: 2026-08-31

**问题/背景**: 顶部导航已有 "8/9 · AGENTS" 入口但点击只落到 Service Ops 占位页。用户希望集中展示后端 `agentflow-control-plane` 的 `GET /agents` 接口返回的全部 AI agents，按运维流水线（detect → diagnose → fix → verify → deliver → learn）呈现为一张「Agent 舰队」视图。分组类型来源经确认改为**后端 `/agents` 返回 `stage` 字段**（前端读 `a.stage` 分组，不再按名字猜）；本次仅前端接入数据渲染，菜单为静态 HTML，分组映射与 API 地址集中配置，为后续「后端菜单可配置」预留切换点。

### 4. `js/app.js` — 新增 initAgentRegistry() 模块 (app.js:4995, 注册 app.js:5212)

**原因**: 拉取 `/agents` 并按流水线分组渲染舰队。关键点：
- `AGENT_API_BASE = localStorage.getItem('agentsBaseUrl') || 'http://localhost:8000'`（沿用 Monitor Targets 的 localStorage 覆盖模式，为后续后端菜单配置预留）。
- **分组完全由后端下发的 `stage` 字段驱动**（与用户确认的决策：不再由前端猜名字）。`AGENT_GROUPS` 为按 stage key 的键控对象（DETECT/DIAGNOSE/FIX/VERIFY/DELIVER/LEARN），`groupOf(agent)` 读 `agent.stage`，未知/缺失 stage 归 OTHER 兜底组，对后端新增 agent 健壮。

```js
var AGENT_GROUPS = {
    detect:   { key: 'detect',   label: 'DETECT',   name: '检测', color: '#3b82f6' },
    diagnose: { key: 'diagnose', label: 'DIAGNOSE', name: '诊断', color: '#8b5cf6' },
    fix:      { key: 'fix',      label: 'FIX',      name: '修复', color: '#f59e0b' },
    verify:   { key: 'verify',   label: 'VERIFY',   name: '验证', color: '#10b981' },
    deliver:  { key: 'deliver',  label: 'DELIVER',  name: '发布', color: '#14b8a6' },
    learn:    { key: 'learn',    label: 'LEARN',    name: '复盘', color: '#ec4899' }
};
var GROUP_ORDER = ['detect', 'diagnose', 'fix', 'verify', 'deliver', 'learn'];
var OTHER_GROUP = { key: 'other', label: 'OTHER', name: '未分组', color: '#6b7280' };

function groupOf(agent) {
    // 分组完全由后端下发的 stage 字段决定；未知/缺失 stage 归 OTHER 兜底
    var g = AGENT_GROUPS[agent.stage];
    return g ? g : OTHER_GROUP;
}
```

### 6. 后端 `multi-agent-workflow/` — `/agents` 返回 `stage` 字段（兄弟仓库，配合本次前端）

**原因**: 用户确认分组不再由前端按名字推断，改为后端下发流水线阶段。三处改动：

- **`agentflow/agents/registry.py`**：`AgentSpec` dataclass 新增 `stage: str = "other"` 字段；新增 `AGENT_STAGES` 映射（detect×7 / diagnose×1 / fix×3 / verify×2 / deliver×1 / learn×1）；`AGENT_REGISTRY` 构造时 `stage=AGENT_STAGES.get(name, "other")`。

- **`tests/test_agents_api.py`**：形状断言改为 `set(item) == {"name", "description", "tools", "stage"}`，并断言 `triage["stage"] == "detect"`。
