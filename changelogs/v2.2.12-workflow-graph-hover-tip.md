# v2.2.12 — 鼠标在节点上停留 1.5s 弹出该节点的描述信息

**日期**: 2026-09-20

**需求/背景**: 鼠标在一个 workflow 节点上停留超过 **1.5s**，弹出该节点的描述信息
（不必先点开右侧详情面板）。

---

## 改动明细

### 1. `src/components/graph/useGraphCanvas.js` — 悬停计时 + 弹出 (331 / 385)

**原因**: 实现需求。

- `HOVER_DELAY_MS = 1500`；`mouseover` 起计时，`mouseout` 取消
- **换节点要重新计时**（`hoverNode !== nid` 才重置）——否则鼠标滑过几个节点会
  沿用前一个的计时，停在第二个上时**立刻**弹出，1.5s 形同虚设
- `mouseout` 用 `relatedTarget` 判断"是否真的离开了这个节点"：节点内子元素之间
  移动（`<g>` → `<rect>`）不收起

### 2. `src/components/graph/useGraphCanvas.js` — `showTip` 定位 (340)

**原因**: 提示要贴在节点旁边。

用节点的 **`getBoundingClientRect()`**（相对容器矩形换算），**不手动乘 zoom**——
后者是"看起来对、一改缩放就偏"的做法，而且现在图区还会滚动。
右边放不下就翻到左边，下边放不下就上移。

### 3. `src/components/graph/nodeTip.js`（新增）

**原因**: 两个页面各有数据源，但**展示哪些字段、叫什么名字应当一致**——
否则同一张 workflow 在 Run Detail 和 Bug Solve hover 出来的东西不一样。

导出 `nodeTipOf(graphNode, runNode) => { title, rows }` 与 `graphNodeById(graph, nid)`。

### 4. `src/components/graph/GraphCanvas.vue` — `nodeTip` prop + 提示容器

### 5. `src/views/runs/RunDetailView.vue` (36) / `src/views/bug-solve/BugSolveView.vue` (55)

各提供一个 `nodeTip(nid)`。

### 6. `css/styles.css` — `.bs-node-tip` (6250)

**`pointer-events: none` 是必须的**：否则提示会盖住节点，鼠标"移出"节点 →
提示闪一下就没，用户根本读不到。

---

## 踩坑记录

### XSS：内容一律 textContent，不拼 HTML

`rows` 是**结构化**的 `[[label, value]]`，引擎用 `document.createTextNode`/`textContent`
逐项渲染。节点 id、agent 名、**error 文本**都是数据——error 尤其可能带上游返回的任意内容，
拼 HTML 就是一个现成的注入口子。

### 我的探针自己被 `</script>` 炸了

为了验证 XSS，我在渲染台的内联 `<script>` 里写了字面量 `'boom <script>alert(1)</script>'`。
**HTML 解析器看到 `</script>` 就提前闭合了脚本标签**，JS 语法直接坏掉，表现为
"节点数 0、控制台无报错"，查了一会儿才发现是自己造的 payload 炸了自己的探针。

内联 `<script>` 里**不能出现字面量 `</script>`**；要用就拆成 `'<' + 'script>'`。

### 数据源名字猜错了

Bug Solve 的 composable 暴露的是 `currentGraph` / `currentNodeData`，**不是** `runData`
（Run Detail 才是 `runData`）。第一版照抄 Run Detail 的写法，会静默取到 `undefined` ——
提示照弹，但**每一格都是 `—`**，看起来像"没数据"而不是"取错源"。

## 影响范围

| 场景 | 预期 | 实际 | 状态 |
|------|------|------|------|
| 停留 1.5s | 弹出 | 探针 `t1000=none` `t3000=block` | OK |
| 换节点 | **重新计时** | 探针在换节点后 0.9s 仍 `none`，1.7s 才 `block` | OK |
| 提示内容 | 当前节点的字段 | `title=scope`（不是上一个节点） | OK |
| 字段数 | agent/kind/status/耗时/tokens/cost（+重试/error） | 7 行 | OK |
| XSS | 不产生脚本节点 | 探针 `xss=无` | OK |
| 提示盖住节点 | 不会导致闪退 | `pointer-events: none` | OK |
| 点击节点 | 提示收起，看右侧详情 | `onClick` 里 `hideTip()` | OK |
| 轮询重绘 | 提示不残留 | `renderGraph` 里 `hideTip()` | OK |
| 生产构建 | 通过 | `npm run build` ✓ | OK |
