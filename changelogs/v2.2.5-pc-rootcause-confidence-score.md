# v2.2.5 — 根因置信度显示分值（原来只有「高/中/低」档位）

**日期**: 2026-09-18

**问题/背景**: 根因卡片上的置信度只显示档位（`置信度 高 · high`），看不到**分值**。

上游 `rca` 节点给的是 **0~1 的小数**（实测 `0.86`），但适配层 `_confidence_chip()`
把它压成 `high/medium/low` 之后**原值就丢了** —— 快照里只剩 `confidence: 'high'`。
后果是审批人分不出「0.86」和「0.51」，而这两者对「敢不敢直接放行」的意义完全不同。

**为什么不直接把数值塞进 `confidence`**：UI 的 `dgxConfChip` 只认档位字符串，且
**spike 历史快照**（`diagnose_decision.snapshot`）里存的也只有档位——换掉 `confidence`
的类型会让历史条目和配色同时失效。故**档位不动，另加一个分值字段**。

---

## 改动明细

### 1. `js/app.js` — `dgxConfChip` 增加可选分值参数 (line 4388)

**原因**: 有分值时显示百分数，没有时退回原样（历史快照 / 上游只给档位）。

```js
+   function dgxConfChip(c, score) {

-           ' · ' + dgxEsc(v) + '</span>';
+           ' · ' + tail + '</span>';
    }
```

### 2. `js/app.js` — `dgxConclusion` 把分流传进去 (line 4473)

```js
-   '<div class="dgx-verdict-meta">' + dgxConfChip(c.confidence) +

```

> 配色仍走 `dgx-conf--{档位}` 的 class，所以档位与分值**永远同色**，不会出现
> 「86% 配低置信度的红色」这种自相矛盾的画面。

### 3. （APM 仓）`src/aiops_apm/diagnosis/from_agentflow.py` — 新增 `_confidence_score()` (line 167, 246)

**原因**: 分值必须在适配层带出来。

```python
def _confidence_score(value: Any) -> int | None:
    """置信度原始分值 → UI 的整百分数（0~100）；取不到 / 不是数值 → None。"""
    if isinstance(value, bool):
        return None                      # bool 是 int 子类，别把 True 当成 1
    try:
        num = float(value)
    except (TypeError, ValueError):
        return None                      # 'high'/'medium' 这类档位串：没有分值
    if num != num or num in (float("inf"), float("-inf")):
        return None
    if 0 <= num <= 1:                    # 0~1 比例 → 百分数
        num *= 100
    if not 0 <= num <= 100:              # 超量纲（500 是 500% 还是别的）→ 宁可不显示
        return None
    return round(num)
```

契约声明同步到 `diagnosis/viewmodel.py` 的模块 docstring。

## 踩坑记录

**档位与分值必须同源**：两者都出自 `rca.confidence` 这**一个**输入，分别经
`_confidence_chip()` / `_confidence_score()` 转换。不要在 UI 侧拿分值反推档位——
阈值（0.8 / 0.5）定义在后端，两边各写一份必然会漂。

**`True` 是 `int` 的实例**：`float(True) == 1.0`，不拦住就会把布尔值渲染成「置信度 100%」。

**超量纲宁可留空**：上游若给出 `500`，无法判断它是 500% 还是「5.00」被误读，
钳成 100% 会伪造一个很确信的数。返回 `None` → UI 退回显示档位，信息量少但不撒谎。
