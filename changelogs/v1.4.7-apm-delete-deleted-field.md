# v1.4.7 — Monitor Target 软删改用独立 deleted 字段（不再复用 enabled）

**日期**: 2026-08-27

**问题/背景**: 此前 Monitor Target 删除复用 `enabled=0` 做软删（删除即禁用）。语义上「删除」与「停用」是两件事：用户可能想停用某个 target（`enabled=0`，仍保留记录）与彻底隐藏（软删）分开处理。需求：软删改用独立 **`deleted`** 字段（1=已删），列表只展示 `deleted = 0` 的记录；点删除时置 `deleted = 1`，`enabled` 保持不变。

---

## 改动明细

### 1. 后端 `aiops-apm-anomaly-detector` — 新增 `deleted` 字段 + 迁移

**原因**: 软删语义与停用解耦。改动点：

- **`migrations/V4__monitor_target_deleted.sql`**（新）：`ALTER TABLE monitor_target ADD COLUMN deleted TINYINT(1) NOT NULL DEFAULT 0 AFTER enabled` + `ADD INDEX idx_tenant_deleted (tenant_id, deleted)`。
- **`src/aiops_apm/storage/monitor_targets.py`**：
  - `_PUBLIC_FIELDS` 增加 `"deleted"`；`_public()`（MySQL tuple 分支）增加 `"deleted": bool(row[9])`。
  - InMemory：`create()` 行内加 `"deleted": False`；`list()` 跳过 `deleted=True`；`delete()` 改置 `r["deleted"] = True`（不再动 `enabled`）；`load_all_targets()`/`list_tenants()` 加 `not r["deleted"]` 过滤。
  - MySQL：`list()`/`get()`/`load_all_targets()` 的 SELECT 补 `deleted` 列；`list()` WHERE 加 `AND deleted=0`；`delete()` 改 `SET deleted=1`；`load_all_targets()`/`list_tenants()` 加 `AND deleted=0`。
- **`src/aiops_apm/router/monitors.py`**：DELETE 文档串改「软删端点（deleted=1，enabled 保持不变）」。

```sql
-- V4__monitor_target_deleted.sql
ALTER TABLE monitor_target ADD COLUMN deleted TINYINT(1) NOT NULL DEFAULT 0 AFTER enabled;
ALTER TABLE monitor_target ADD INDEX idx_tenant_deleted (tenant_id, deleted);
```

### 2. 前端 `js/app.js` — 删除确认文案

**原因**: 确认弹窗文案保持简洁，不带实现细节。改动点：`confirmDialog('Delete monitor target ' + id + '?', ...)`（软删细节由后端 deleted 字段承担，前端提示不暴露）。

---

## 踩坑记录

- **调度器必须排除已删 target**：`load_all_targets`/`list_tenants` 是 scheduler（scheduler.py:64-65）与 alerts 路由的数据源。由于删除后 `enabled` 仍可能是 1，若不按 `deleted=0` 过滤，已删 target 仍会被调度采集 —— 两处都必须加 `deleted=0`。
- **MySQL SELECT 列序与 `_public` tuple 索引对齐**：`_public` 取 `row[9]` 为 `deleted`，所有喂 `_public` 的 SELECT（list/get/load_all_targets）都必须补第 10 列，否则 tuple 索引越界（v1.4.5 同类坑）。
- **迁移测试硬编码脚本数**：`test_migrations.py` 把脚本版本列表/应用数量写死（`[1,2,3]`、`applied==3`、`applied==2`），新增 V4 必须同步更新为 `[1,2,3,4]`、`applied==4`、`applied==3`，否则迁移单测失败。
- **`get()` 不做 deleted 过滤**：直接按 target_id 取行，返回已删记录（`deleted=True`），供审计/排查；仅 list/调度路径过滤。
