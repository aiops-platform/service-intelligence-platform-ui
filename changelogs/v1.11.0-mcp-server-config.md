# v1.11.0 — MCP Server 配置页面

**日期**: 2026-09-02

**问题/背景**: Agent 的工具此前**硬编码绑定 function tool**（`TOOL_REGISTRY` → L1 只读 / L2 执行）。需要在一个页面**配置通用的 MCP server**（stdio / streamable HTTP / SSE 任意类型），并把 MCP server **绑定给 agent**——agent 运行时通过 AgentScope `MCPClient` 调 MCP 工具，与既有 function tool **共存**（hybrid toolkit，同一 agent 在一个 react 循环里两类工具都能调）。

**后端配套**（`multi-agent-workflow` 仓库，跨仓库改动，见下方「后端配套」章节）：新增 `/mcp-servers` CRUD + `/mcp-servers/test` + `/{mid}/tools`；运行时 `MCPClientManager` 把配置解析为 AgentScope `MCPClient`，注入 `AgentNodeRunner`（有 `DEEPSEEK_API_KEY` 时）。文档：`docs/MCP_SERVER_CONFIG_zh-CN.md` + `AGENTFLOW_UI_INTEGRATION_RESEARCH_zh-CN.md` §9 端点契约。

### 2. `index.html` — 新增 `#page-mcp-servers` 页面面板 (index.html:1553)

**原因**: 左右两栏布局——左栏 `.mcp-panel` = 配置表单 + 已存列表；右栏 `.mcp-result` = 测试/工具探测结果。

左栏表单字段（按 transport 显隐两组 config 字段，`#mcpFieldsStdio` / `#mcpFieldsHttp`）：
- `#mcpName`（server 名，仅字母/数字/_/-，同时是 LLM 侧工具名前缀）
- `#mcpTransport`（select：stdio / http）
- **stdio**：`#mcpStdioCommand`（必填）+ `#mcpStdioArgs`（每行一个）+ `#mcpStdioCwd`
- **http**：`#mcpHttpUrl`（必填，`/sse`/`/messages/` 结尾自动 SSE）+ `#mcpHttpHeaders`（JSON）+ `#mcpHttpStateful`（勾选=常连）
- `#mcpEnabled`（停用 = 运行时不再注入任何 agent）
- `#mcpAgents`（勾选绑定 agent，数据来自 `GET /agents`）
- `#mcpEnableTools` / `#mcpDisableTools`（可选白/黑名单，逗号/空格分隔）
- 动作：`#mcpTestBtn`（测试连接）`#mcpNewBtn` `#mcpSaveBtn`（Save Server / Update Server）
- 错误条 `#mcpError`；已存列表 `#mcpList`（transport · 创建时间 · 绑定 agent 徽章 · disabled 半透明；每行 查看工具 / Edit / Delete）

右栏 `.mcp-result`：`#mcpResultMeta`（transport · tools 数）+ `#mcpTools`（工具卡片列表 / 连接失败红条）。复用 `.apm-field`、`.btn*`、`.si-refresh-btn` 组件与现有 CSS 变量。

### 4. `js/app.js` — 新增 `initMcpServers()` 模块 (app.js:5993)

**原因**: 实现 MCP Server 配置页全部交互，仿 `initWorkflowStudio()` 模式（ES5、局部 `getEl/setText`、`localStorage` 可覆盖后端地址）。

`initMcpServers()` 内部：
- `MCP_API_BASE = localStorage.getItem('mcpBaseUrl') || localStorage.getItem('workflowBaseUrl') || 'http://localhost:8000'`（沿用 workflowBaseUrl，可单独覆盖 mcpBaseUrl）；`AGENTS_API_BASE` 沿用 `agentsBaseUrl`
- `loadServers()` → `GET /mcp-servers` → `renderList()`（transport / 创建时间 / 绑定 agent 徽章 / disabled 半透明）
- `loadAgentOptions()` → `GET /agents` → `renderAgentOptions()`（agent 多选 chips，数据驱动；无数据给兜底提示不白屏）
- `readConfig()` → 按 transport 从表单组 config JSON（stdio：command/args/cwd；http：url + headers 合法 JSON 校验 + timeout）
- `buildBody()`（校验 name/command/url + tool 列表解析）→ `POST/PUT /mcp-servers[/{mid}]`；400 读 `data.detail`
- `testConnection()` → `POST /mcp-servers/test`（不落库）→ `renderTools(data)`
- `viewTools(mid)` → `GET /mcp-servers/{mid}/tools` → 同 `renderTools`（形状一致：`{ok, transport, tools:[{name,description,read_only,llm_name}], error?}`）
- `renderTools()` → 工具卡片：`mcp__{server}__{tool}` 精确名（紫色 mono）+ 只读/非只读徽章（只读=绿「自动 ALLOW」、非只读=琥珀「需 allow 规则」）+ 描述
- `edit(mid)` → `GET /mcp-servers/{mid}` → `fillForm` 回填（transport 分派 config 字段 + headers 反序列化为 JSON + agent chips 勾选）→ SaveBtn 变「Update Server」
- `remove(mid)` → confirm → `DELETE /mcp-servers/{mid}`
- `resetForm()` / `setTransportUi()`（transport select change 切换 stdio/http 字段显隐）
- `_pageRefreshers['page-mcp-servers'] = loadServers`（切回本页自动刷新）

## 后端配套（multi-agent-workflow 仓库）

本页面调用的 MCP server 配置 CRUD / 测试连接 / 运行时注入接口在 `multi-agent-workflow` 中新增（跨仓库配套改动）：
- `agentflow/api/mcp_store.py`（新建）— `MCPStore`：`mcp_servers` 表（与 workflow/state 同库异表，复用 `settings.state_db_path`），aiosqlite 惰性连接；save/list/list_enabled/get/update/delete
- `agentflow/agents/mcp_manager.py`（新建）— `MCPClientManager`：配置 JSON → AgentScope `MCPClient`（stdio 强制 stateful / http 按 url 自动 SSE 或 streamable）；`load` 热启动、`refresh_server` 热刷新、`evict`/`close_all`、`clients_for_agent` 绑定过滤 + 失联一次重连、`allow_names_for_agent` 预计算精确 `mcp__{name}__{tool}` 名、`test_connection` 收敛 `{ok,tools,error}`
- `agentflow/agents/mcp.py` `build_toolkit` → **hybrid**（function tool + MCP client 共存；防御性剔除 stateful 未连接 client；旧调用方不传 `mcp_clients` 行为不变）
- `agentflow/agents/runner.py` `AgentNodeRunner` — 每节点取绑定 client + allow 名单 → `build_toolkit(mcp_clients)` + `build_permission_context(allow_extra=…)`（allow 先于 `build_agent`）
- `agentflow/api/app.py` — `POST /mcp-servers`（201）/ `GET` / `GET {mid}`（404）/ `PUT` / `DELETE` / `POST /mcp-servers/test`（**先于 `/{mid}` 注册**）/ `GET /{mid}/tools`；400 中文校验（name charset/唯一、transport、command/url 必填、enable/disable 重叠）；stdio 强制 stateful；init() 注入 `AgentNodeRunner(mcp_manager=…)`；shutdown `close_all()`
- `scripts/mock_mcp_server.py`（新建）— mcp 1.x FastMCP，三工具覆盖三种权限形态：`get_weather`（只读 auto-ALLOW）/ `query.repo`（含 `.`，验证 sanitize → `queryxrepo`）/ `send_alert`（非只读，需 allow 规则）；stdio 为主 + `--http` 供联调
- `tests/test_mcp_store.py` / `test_mcp_api.py` / `test_mcp_manager.py` / `test_mcp_integration.py`（新建）— 全绿
- `docs/MCP_SERVER_CONFIG_zh-CN.md`（新建）+ `docs/AGENTFLOW_UI_INTEGRATION_RESEARCH_zh-CN.md` §9 端点契约

> 端点契约：CRUD/校验/测试连接/工具形状与 400/404 语义见 `multi-agent-workflow` 文档 §9；`read_only`（只读自动 ALLOW / 非只读需 allow）与 `llm_name`（AgentScope 精确名，`query.repo` → `queryxrepo` sanitize）是前端徽章语义来源。
