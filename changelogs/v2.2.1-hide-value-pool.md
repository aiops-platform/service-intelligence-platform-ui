## 踩坑记录

- **`Edit` 替换 `/9 · ` → `/8 · ` 时尾部空格被吞了**，8 处全变成 `'1/8 ·CONSTELLATION'`
  （缺 `·` 后的空格）。已用 `sed 's|/8 ·\([A-Z]\)|/8 · \1|g'` 修回，并按字节 `od -c` 复核。
  **教训**：以空格结尾的 `new_string` 不可靠，机械批替换改用 sed 或把空格包进更大的锚点。
- **`EMPTY_DOMAINS` 是 5 不是 4**：它 = `NAV.filter(n => !n.sidebar)`，**包含**已有组件的
  constellation 与 biz-ops。改 `NAV` 顶部那句域数注释时一度写成 4，已订正。
  「空壳域」在这个仓里有**两个不同口径**：`EMPTY_DOMAINS` 的成员（5 个）vs
  真正落回 `page-service-ops` 的（3 个）。
- **差点去改 `js/app.js` 的 else 分支名单**：那份名单是旧单页世界自己的实现，
  只在独立打开 `index.html` 时走到，与 Vue 侧 NAV 不共享代码。旧入口里 Value Pool 那个
  nav-item 还在、也该在，所以那边 5 个不变 —— 改了反而弄坏旧入口。
- **没有新增 `hidden` 标志位**：那等于给「可见性」引入第三套语义（`NAV` 成员资格 +
  `EMPTY_DOMAINS` 派生 + 渲染时过滤）。「从 `NAV` 摘掉」本身已经同时表达了全部三者。
