# v1.4.3 — Toast 提示重设计：顶部居中 + 适配 SIP 风格

**日期**: 2026-08-27

**问题/背景**: `_showToast` 全局提示框原为右下角深色胶囊（`bottom: 24px; right: 24px`），位置在底部且颜色对比弱，用户反馈不明显。本次改为**顶部居中**，并重新设计为 SIP 卡片风格（白底 + 边框 + 柔和阴影 + 类型色条），顶栏（52px）下方 64px 处弹出，全局所有 toast 统一生效。

---

## 改动明细

### 1. `css/styles.css` — Toast 容器定位与消息样式重设计 (line 4507-4550)

**原因**:
- **位置**：`bottom/right` → `top: 64px; left: 50%; transform: translateX(-50%)`（顶部居中；固定 `header` 高 52px，64px 正好在其下方，不遮挡顶栏也不被顶栏盖住）。
- **风格**：深色胶囊 → SIP 卡片（`background: var(--bg-white)` + `border: 1px solid var(--border-color)` + `border-radius: 8px` + `box-shadow: 0 8px 24px`），文字用 `var(--text-primary)`、字号 13px，与全站卡片/设计令牌一致。
- **类型区分**：由整块背景色改为**左侧 4px 色条**：success=`var(--accent-green)`、info=`var(--accent-blue)`、error=`var(--accent-red)`；删除原硬编码 `#059669/#3b82f6/#dc2626` 背景色（含遗留的 `.toast-msg.error { background: #dc2626; }`，已随本次合并清理）。
- **动画**：`toastIn` 由 `translateY(12px)`（自下而上）改为 `translateY(-10px)`（自上而下滑入），贴合顶部位置；`max-width: 60vw` 防长文本撑出屏幕。

```css
/* before（右下角深色胶囊） */
.toast-container { position: fixed; bottom: 24px; right: 24px; z-index: 99999; }
.toast-msg { padding: 10px 18px; border-radius: 18px; font-size: 12px; color: #fff; background: #1e293b; }
.toast-msg.success { background: #059669; }
.toast-msg.info { background: #3b82f6; }
/* after（顶部居中白卡片 + 类型色条） */
.toast-container { position: fixed; top: 64px; left: 50%; transform: translateX(-50%); z-index: 99999; align-items: center; }
.toast-msg { padding: 10px 16px; border-radius: 8px; font-size: 13px; color: var(--text-primary); background: var(--bg-white); border: 1px solid var(--border-color); border-left: 4px solid var(--accent-blue); box-shadow: 0 8px 24px rgba(0,0,0,0.12); }
.toast-msg.success { border-left-color: var(--accent-green); }
.toast-msg.info { border-left-color: var(--accent-blue); }
.toast-msg.error { border-left-color: var(--accent-red); }
```

### 2. `css/styles.css` — 删除遗留 `.toast-msg.error` 硬编码规则 (原 line 4732)

**原因**: 该规则与主 toast 块分开写在 APM 样式区末尾，`background: #dc2626` 与新设计冲突；已并入主块的 `border-left-color: var(--accent-red)`，此处删除避免死代码。

---

## 踩坑记录

- **`_showToast` 是全局机制**：本消息（`requireLoaded()` 里 `Save the target first, then run Test / Run`）与「Copied / Action submitted / Deleted / Save failed」等共用同一容器；本次改容器位置/样式 = 全局 toast 统一从右下角移到顶部居中，行为一致，符合「全局提示更明显」的诉求。
- **顶部偏移避开 header**：`header` 为 `position: fixed; height: 52px; z-index: 100`，toast `top: 64px` 在其下方、`z-index: 99999` 更高，互不遮挡。
- **fade-out 变换**：容器本身带 `transform: translateX(-50%)`，toast 子元素的 `translateY` 动画独立于容器变换，无冲突。
