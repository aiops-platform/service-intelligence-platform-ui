# v1.2.1 — 在 logo 区域与导航菜单之间添加竖线分割

**日期**: 2026-07-06

**问题/背景**: SIP SERVICE INTELLIGENCE PLATFORM 与右侧导航菜单之间缺少视觉分割，用户要求在两者之间添加竖线分离。

---

## 改动明细

### 1. `css/styles.css` — `.logo-area` 添加右边框 (line 56-61)

**原因**: 在 logo 区域和导航菜单之间增加视觉分隔

```css
/* before */
.logo-area {
    display: flex;
    align-items: center;
    gap: 10px;
    margin-right: 40px;
}

/* after */
.logo-area {
    display: flex;
    align-items: center;
    gap: 10px;
    margin-right: 20px;
    padding-right: 20px;
    border-right: 1px solid var(--border-color);
}
```

- `border-right`：1px 竖线，颜色使用设计令牌 `var(--border-color)` (#e5e7eb)，与整体风格统一
- `padding-right: 20px`：logo 内容与竖线之间的间距
- `margin-right: 20px` 配合 `padding-right` 保持总间距 40px 不变
