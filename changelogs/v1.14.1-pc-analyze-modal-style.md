# v1.14.1 — Problem Center Analyze 弹框：按钮下移留白 + 主按钮改平台紫

**日期**: 2026-09-07

**问题/背景**: v1.14.0 的 Problem Center Analyze 弹框（`#pcAnalyzeOverlay`）里，**Cancel / Analyze 按钮紧贴 Workflow 下拉框**（
`.apm-confirm-actions` 无 margin-top，按钮区与 select 底部间距为 0）；且主按钮用的全局 `.btn-primary` 是近黑
`var(--text-primary) #111827`，观感偏重。用户要求：① 按钮往下挪一些、与下拉框留白；② Analyze 按钮换个适配本应用样式的颜色，
经确认选 **平台紫 #8b5cf6**（`--accent-purple`）。

**方案**: 纯 CSS、**id 作用域限定**（`#pcAnalyzeOverlay ...`），只影响本弹框，不改全局 `.btn-primary` 的黑色
（其余弹窗的确认/主按钮仍为原样）。无需改 `index.html` / `js/app.js`。

---

## 改动明细

### 1. `css/styles.css` — Analyze 弹框按钮区样式 (styles.css:4604-4610)

**原因**: 全局 `.apm-confirm-actions { display:flex; justify-content:flex-end; gap:8px; }` 无 margin-top → 按钮贴住下拉框；
主按钮黑色因 `.btn-primary { background: var(--text-primary) }`。两条都以 `#pcAnalyzeOverlay` 作用域覆盖，互不影响其他弹窗。

```css
/* pcAnalyzeOverlay（Problem Center Analyze 弹框）：按钮区与下拉之间留白；
   主按钮用平台紫强调（作用域限定，不改变全局 .btn-primary 的黑色）。 */
#pcAnalyzeOverlay .apm-confirm-actions { margin-top: 24px; }
#pcAnalyzeOverlay .apm-confirm-actions .btn-primary {
    background: var(--accent-purple);
    color: #fff;
}
```

- `margin-top: 24px` → 按钮区与 Workflow 下拉框之间留出垂直间距；
- `background: var(--accent-purple)`（`#8b5cf6` 平台紫）+ `color:#fff` → 主按钮强调色，白字保证对比度；
- 作用域仅 `#pcAnalyzeOverlay`：Bug Solve / MCP / Monitor / Approval 等其他弹框的 `.btn-primary` 仍是全局近黑，不受影响。
