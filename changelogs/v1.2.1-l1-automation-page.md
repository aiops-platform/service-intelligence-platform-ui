# v1.2.1 — L1 Automation 页面

**日期**: 2026-07-07

**问题/背景**: Business Ops > Ticket Workspace > L1 Automation 需要专属页面，展示 L1 Agent 自动分类、转单和关单的工单管理功能，参考 `knowledge/deepseek_html_20260707_187e8a.html` 设计。

---

## 改动明细

### 1. `index.html` — 新增 `#page-l1-automation` 页面面板

页面组成：
- 面包屑：Business Ops › Ticket Workspace › **L1 Automation**
- 4 个 KPI 卡片（Total Tickets / Own System (Keep) / Other System (Transfer) / Auto-Process Rate）
- 搜索工具栏 + 筛选芯片（All / Own System / Other System / Pending）
- 7 列表格（Ticket ID / Title / System / Classification / Confidence / Status / 操作列）
- 分页信息栏

### 2. `css/styles.css` — L1 Automation 专属样式

新增：
- `.cls-tag` — 分类标签（own 绿 / other 红 / pending 蓝）
- `.l1-status` — 状态指示器（带色点）
- `.btn-l1` — 操作按钮（Process / 处理后禁用态）
- `.ticket-meta-grid` — 详情抽屉中的 2 列元数据网格

### 3. `js/app.js` — 新增 `initL1Automation()` 函数 + 接入 init()

`initL1Automation()`：
- 8 条 mock 工单数据（INC-001 ~ INC-008），覆盖 SIP / Billing / CRM / Monitor / Email 系统
- 分类：本系统（own）升级到 L2 / 其他系统（other）转单并关闭
- 置信度进度条（high/medium/low）
- Process 按钮点击后自动分类处理（own → escalated, other → transferred）
- 搜索过滤（按 ID、标题、系统名）
- 筛选芯片（All / Own System / Other System / Pending）
- 详情抽屉展示工单元信息、分类决策和 Processing Log

`init()` 中新增 `initL1Automation()` 调用。

### 4. sidebar 路由更新

点击 `l1-automation` → `showPage('page-l1-automation')`
