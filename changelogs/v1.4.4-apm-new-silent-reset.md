# v1.4.4 — 点 New 不再弹「Form reset to New」提示

**日期**: 2026-08-27

**问题/背景**: 列表点 **New** 时，点击处理是 `resetForm(); openModal();`，而 `resetForm()` 内部无条件 `_showToast('Form reset to New')` —— 导致「新建」动作先弹出一条重置提示，语义上属于 Reset 按钮，出现在 New 上既冗余又令人困惑（弹窗标题 hint 已显示 New Target）。

---

## 改动明细

### 1. `js/app.js` — `resetForm()` 增加 `silent` 参数 (line 3782、3800)

**原因**: 把「重置提示」从 New 的调用链里去掉，仅 Reset 按钮触发时提示。`resetForm(silent)` 参数为 truthy 时跳过 `_showToast`。

```js
// before
function resetForm() { ... window._showToast('Form reset to New', 'info'); }
// after
function resetForm(silent) { ... if (!silent) window._showToast('Form reset to New', 'info'); }
```

### 2. `js/app.js` — New 按钮调用 `resetForm(true)` (line 3979-3982)

**原因**: New 只重置表单并开弹窗，不提示「Form reset to New」。

```js
getEl('apmNewBtn').addEventListener('click', function () {
    resetForm(true);   // silent：不弹重置提示
    openModal();
});
```

### 3. `js/app.js` — Reset 按钮包一层，避免事件对象误当参数 (line 3978)

**原因**: Reset 原直接绑定 `resetForm`，点击事件对象会作为首个实参传入——若不加保护，事件对象是 truthy，会被当成 `silent` 导致 Reset 也不提示。包一层匿名函数，保证 Reset 仍提示。

```js
// before（事件对象会误作 silent 实参）
getEl('apmResetBtn').addEventListener('click', resetForm);
// after
getEl('apmResetBtn').addEventListener('click', function () { resetForm(); });
```

---

## 踩坑记录

- **事件对象污染参数**：`addEventListener('click', resetForm)` 会把 Event 对象作为第一个参数传给 `resetForm(silent)`，Event 恒为 truthy → 提示被静默。必须用匿名函数包装，或让 `silent` 显式传。

## 影响范围

| 场景 | 预期 | 实际 | 状态 |
|------|------|------|------|
| 列表点 New | 打开空表单弹窗（hint=New Target），**不弹**「Form reset to New」 | 已改，待浏览器确认 | 待验证 |
| 弹窗点 Reset | 重置表单并弹「Form reset to New」 | 已包一层保证提示，待浏览器确认 | 待验证 |
| Edit / Test 打开弹窗 | 不受影响（不走 resetForm） | 逻辑未动 | OK |
