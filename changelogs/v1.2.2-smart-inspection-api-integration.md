# v1.2.2 — Smart Inspection 接入后端 API

**日期**: 2026-07-10

**问题/背景**: Smart Inspection 页面使用前端硬编码 mock 数据，需要改为通过后端 API `GET /api/sip-aiops/app-indicator` 获取真实数据，null 值统一显示为 `-`。

---

## 改动明细

### 1. `js/app.js` — 重写 `initSmartInspection()` 函数 (line 823-982)

**原因**: 将硬编码 mock 数据替换为后端 API 获取、新增 loading/error/empty 状态管理、null 值安全处理。

- 新增 `API_URL` 常量、`services` 状态、`isLoading` 锁
- 新增 `fmt(val, suffix)` / `fmtText(val, suffix)` — null-safe 格式化工具，null 展示为 `<span class="si-null-value">-</span>`
- 新增 `metricClass(val)` — 阈值判定（>=90 critical, >=70 warning, null 为 null-val）
- 新增 `deriveStatus(s)` — 当 API status 为 null 时从 cpu/mem/disk 指标推导
- 新增 `fetchServices()` — fetch API 请求 + loading 状态管理 + 错误处理
- 新增 `transformService(item)` — API 数据转 UI 模型
- 新增 `showLoading()` / `hideLoading()` / `showError()` / `hideError()` / `setRefreshSpinning()` — 状态 UI 控制
- 重写 `renderSITable()` — 适配新数据模型，去除 baseline 进度条逻辑
- 重写 `renderMetricCell(val)` — 单指标单元格渲染
- 重写 `updateSIStats()` — 从实际数据计算 KPI 统计
- 重写 `openSIDetail()` — 展示 API 全量字段（新增 owner、description、netInRate、netOutRate、uptimeSeconds、restartCount、enabled、lastUpdateTime）
- 新增 `fmtUptime()` — 秒数格式化为 d/h/m
- 新增刷新按钮、重试按钮事件绑定
- 初始化时调用 `fetchServices()` 替代 `renderSITable(services)`

### 2. `css/styles.css` — 新增加载/错误/null 状态样式 (line 1661+)

**原因**: 支持 API 请求的各种状态展示。

新增：
- `.si-loading-overlay` / `.si-loading-spinner` — 表格加载遮罩 + 旋转动画
- `.si-error-bar` / `.si-error-msg` / `.si-error-icon` — 错误提示条（红色）
- `.si-null-value` — null 值 `-` 的灰色斜体样式
- `.si-metric-val.null-val` — null 指标值的置灰样式
- `.si-alert-badge.null-alert` / `.si-status.null-status` — null 状态的徽章样式
- `.si-refresh-btn` / `.si-refresh-icon` — 刷新按钮样式 + 旋转动画

### 3. `index.html` — Smart Inspection 页面头部 + 状态容器 (line 808-817, 863-888)

**原因**: 添加刷新按钮和 loading/error UI 容器。

- 页面标题右侧新增 Refresh 按钮（`#siRefreshBtn`）+ API Live 徽章
- 表格上方新增错误提示条（`#siErrorBar`，含 Retry 按钮）
- 表格容器内新增加载遮罩（`#siLoadingOverlay`）
