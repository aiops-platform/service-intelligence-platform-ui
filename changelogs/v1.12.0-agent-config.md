## 交互要点（对照后端语义）

- **覆盖即存值、NULL 即回退**：Edit 文本按 `stored` 回填——留空字段保存 = 清掉该 agent 的覆盖、回退内置默认；
  内置行的「内置默认」内容显示为 placeholder，避免手滑把整份默认写进 DB。
- **绑定 radio 三态**：默认「全部 enabled」→ 提交 `mcp_server_ids: null`（未绑定，跟随全局新增 enabled server）；
  选「指定 server」→ 提交勾选数组（可空 `[]` = 明确不绑）。
- **内置 vs 自定义**：内置行 DELETE 置灰；只可通过编辑清空覆盖回退。New 只能建 custom（name/role/prompt 必填）。
- **disabled agent**：列表徽章 + Edit 勾选取消 → 后端 `enabled=false` → 运行时节点击短路（不调 LLM）。
