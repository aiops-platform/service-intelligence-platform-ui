# v1.18.0 — feat: View analysis 右栏节点详情升级：Input/Output 转人读表格 + MCP 调用 / 思维链(Reasoning) / 证据链(执行时间线)

**日期**: 2026-09-07

**需求背景**: View analysis 主弹框右栏点节点后只平铺原始 JSON（Output/Prompt 两个 tab 看 `output` / `params`），信息密度低、不可读。
用户希望把节点的输入/输出流**总结成人能看的表格**，且是**通用样式**（其他/新增节点零成本复用）；同时展示该节点 agent 对应的
**MCP server 调用**内容；若节点有**思维链**也展示思维链；并展示**证据链**（节点如何一步步走到该输出）。

已确认设计：**纵向分区 + 可折叠**；证据链用**执行时间线**；文案**英文**。

**数据源（已核实，无后端改动）**: 聚合 `GET /runs/{id}` 只给节点 `{status,output,params,tokens,cost,prompt}`，不含 MCP/思维链明细；
节点级明细在 **`GET /runs/{run_id}/traces?node_id=&limit=500`**（agentflow 已有，按 `(node_id,seq)` 升序），kind：
`node`（汇总）/ `llm_call`（`name`=模型名，payload 含 `reasoning`=思维链、`usage`）/ `tool_call`（`name=mcp__{server}__{tool}`，
payload 含 `server` / `is_mcp` / `read_only` / `input` / `result` / `result_state`）/ `denied`。mock/approval 节点无明细 → UI 自动降级。

## 改动明细

### 1. `js/app.js` — 右栏详情整体重写（`initProblems` 内 run viewer 块）

- 状态（app.js:4052-4062）：删 `pcRunTab`（tab 交互取消）；新增 `pcRunDetailNode`（当前详情节点）、`pcRunSecOpen`（分区开合状态）、
  `pcRunTraces`（节点 trace 缓存 nid→`{items,ts,error}`）、`pcRunTraceReq`（在途请求防重）。开/关 run 时（openProblemRun/closeProblemRun）统一复位。

- `pcRunTraceEnsure(nid,st)`（app.js:4267）：**按需拉节点 trace**——终态节点成功拉一次即缓存不再重复请求；running 节点节流约每 2.5s 刷新
  （看新增 MCP/思维链）；请求失败缓存 error，重进节点自动重试；响应到达且仍是当前选中节点时重渲染。

- 通用可复用渲染器（供 Input/Output/args/result，**任意新节点类型零成本复用**）：
  - `pcRunValHtml`（app.js:4322）递归把任意 JSON 值转人读 HTML：字符串若是 JSON（`{`/`[` 开头）解析后递归；
    超长/多行字符串转 `pcRunBlk` 预格式块（见下）；对象/数组分派到 `pcRunObjHtml`/`pcRunArrHtml`。
  - `pcRunObjHtml`：**key-value 表**（`.nd-row` = 键列 + 值列，嵌套对象左缩进带竖线层级）。
  - `pcRunArrHtml`：纯标量数组 → 列表；对象数组 → 每元素一张 `.nd-card` 卡片。
  - `pcRunBlk`（app.js:4307）：长文本预格式块 + **Show more/less** 裁剪按钮（避免大结果/大输出撑爆面板）。
  - `pcRunResultHtml`：工具 result 统一转文本块展示。

- 明细区块构建器：
  - `pcRunToolCard`（app.js:4395）：一条 MCP/工具调用卡片——`MCP`/`tool` 标签、`{server} / {tool}`（由 `mcp__{server}__{tool}` 解析）、
    `read-only` / `result_state` 徽标、args 表格 + result 文本块。`pcRunDeniedCard`：被 DENY 工具 + reason。
  - `pcRunReasoningItem`（app.js:4431）：一次模型调用——模型名 + `in/out tokens` + **Reasoning 思维链**文本。
  - `pcRunTimelineHtml`（app.js:4451）：**证据链执行时间线**——按 seq 全序，每个事件 = `#序号` + LLM/MCP/tool/denied 徽标 +
    标题 + 用量/状态 + 展开内容（思维链 / tool result），横向色点按类型着色。
  - `pcRunSec(title,key,count,body)`：折叠分区壳，开合写入 `pcRunSecOpen`，**轮询重渲染后保持一致**。

- `renderRunDetail(nid)`（app.js:4498）重写：
  - 头部保留 节点名 + 状态徽章，新增 agent / kind 标签 + tokens/cost；
  - **Input**（params）、**Output** 分区默认展开，走通用表格渲染（Output running 中 / 空 → 占位文案）；
  - 有明细时追加 **Tools & MCP Calls**（含 denied）、**Reasoning**、**Evidence Trail**，默认折叠、标题带数量；
  - 无明细的节点（approval/mock）→ "No per-step trace… / Awaiting step detail…" 提示；底部 **Raw JSON** 兜底折叠区保原文可查。

- 事件委托（`#pcRunDetail`，原 tab 监听改造）：点 `.nd-sec-trigger` 折叠/展开分区并写回 `pcRunSecOpen`；点 `.nd-blk-btn` Show more/less。

### 2. `css/styles.css` — `#pcRunDetail` 作用域新样式（styles.css:5136 起）

- 头部 `.nd-head` 与 agent/kind 徽章、`.nd-sec` 折叠分区（三角箭头旋转、`.open` 显示 body）、`.nd-sec-count` 数量圆标。
- 通用 key-value 树：`.nd-row`（键 168px 列 + 值列）/ 嵌套 `.nd-obj` 左缩进竖线 / `.nd-card`（对象数组卡片）。
- 长文本：`.nd-blk .nd-pre` 预格式 + `.clipped` 裁剪（max-height 220）配合 `.nd-blk-btn` Show more。
- MCP/工具卡片 `.nd-call`、kind 标签 `.nd-k-*`（MCP/tool/LLM/denied）、read-only/result_state 徽章。
- 证据链时间线 `.tl`：左侧竖线 + 事件圆点（LLM 紫 / tool 蓝 / denied 红）、事件徽章。
- 复用现有顶层 `.bs-badge*` / `.bs-detail-*`，其余均作用域限定在 `#pcRunDetail`，不影响 Bug Solve / 其他页面。
