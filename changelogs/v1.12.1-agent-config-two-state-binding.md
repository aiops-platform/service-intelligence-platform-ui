# v1.12.1 — Agent→MCP server 绑定改「两态」：没配置就等于没有 server

**日期**: 2026-09-03

**问题/背景**: v1.12.0 的 `mcp_server_ids` 是**三态**（`NULL`=全部 enabled server / `[]`=明确不绑 / `[mid,…]`=精确子集），
UI 用 radio「全部 enabled(默认/未绑定) vs 指定 server」表达。走查时确认这不理想——「未配置」默认跟随**全部** enabled
server，会让没做任何绑定选择的 agent 也能看到（并可能调用）后来新增的所有 server 工具，语义不可预期。

**本次变更**：去掉「全部 enabled」这个动态默认，改**两态**——`NULL`/`[]`（写入归一 NULL）= **没有 MCP server**
（该 agent 无 MCP 工具）；只有显式勾选绑定的 server 子集（`[mid,…]`）才下发。UI 默认 radio 改为「不绑定 MCP server」。

> 跨仓库：语义核心在后端 `multi-agent-workflow`（resolver / store 归一 / manager 过滤 / bound_servers / 文档），
> 见其 `docs/AGENT_CONFIG_DB_zh-CN.md`（v1.12.1 注记）与 `docs/MCP_SERVER_CONFIG_zh-CN.md`。本文为 SIP 侧执行日志。

## 改动明细（SIP 三文件）

### 1. `index.html`
- 绑定区 radio 改两态（Agent Config 弹窗 `#agentCfgBindNone`，index.html:1805）：
  - 默认项「全部 enabled(默认/未绑定)」→ **「不绑定 MCP server（默认，无 → 该 agent 没有 MCP 工具，需下方指定才有）」**；
  - 第二项不变：「指定 server（勾选整 server → 该 agent 只见所选 server 的 enabled 工具）」。
- 其余弹窗结构（textareas、复选卡容器、Save/Cancel）不动。

### 2. `js/app.js` — `initAgentConfig()`
- `bindText(s)`（app.js:6636）：`bound_servers` 空数组 → `{kind:'none'}`（不再有 v1.12.0 的 `{id:'*'}`「全部 enabled」哨兵
  与 all 分支）。
- `renderTable()` MCP Servers 列（app.js:6665）：`kind==='none'` → `<span class="agc-mcp-none" title="无 MCP server：
  该 agent 没有 MCP 工具（Edit 勾选 server 后生效）">—</span>`；否则绑定 server 名（`,` 分隔 + hover 全名）。
- `setBindMode`（app.js:6740）/`bindMode()`（app.js:6748）：none ↔ specific 两态（不处理「all」）。
- 表单初始/回填：`resetForm`（New，app.js:6796）`setBindMode('none', [], false)`；`fillFromDetail`（Edit，app.js:6830-6831）
  `mcp_server_ids` 为数组 → specific+勾选；`NULL`/`[]`（无绑定）→ none。
- `buildBody`（app.js:6894-6895）：默认 `mcp_server_ids = null`（两态 = 无 MCP server）；仅 `bindMode()==='specific'`
  才写勾选 id 数组。注释与 docstring 同步两态语义。
- 列表 MCP Servers 列不再显示「全部 enabled」灰斜体文案。

### 3. `css/styles.css`
- 文件尾（styles.css:5980）：删除 `.agc-mcp-all`，新增 `.agc-mcp-none { cursor: help; }`（无绑定 cell：`—`，hover 出提示）。

## 交互要点（对照后端语义）

- **两态**：radio 默认「不绑定 MCP server」→ 提交 `mcp_server_ids: null`（后端 `[]` 也会被归 NULL）→ **该 agent 没有
  MCP 工具**；选「指定 server」→ 提交勾选数组（非空 = 精确子集）。不再有「未绑定 = 跟随全部 enabled」的中间态。
- **列表列**：无绑定 agent 的 MCP Servers 列显示 `—`（hover 提示「无 MCP server…」）；绑定显示所选 server 名。
- Edit 回填：绑定了 server 的 agent 进弹窗 radio 落到「指定 server」并勾选；未绑定的落到「不绑定」。
- **未注入 resolver 的回退仅存在于后端独立用法/测试**（`MCPClientManager` 不注入 `server_ids_for` 才返回全部 enabled）；
  app 运行时注入 resolver 后即两态，UI 无「全部」选项。
