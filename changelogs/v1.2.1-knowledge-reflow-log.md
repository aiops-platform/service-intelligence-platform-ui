# v1.2.1 — 新增 Knowledge Reflow Log 详情页

**日期**: 2026-07-06

**问题/背景**: 点击左侧导航 "Knowledge Reflow Log" 后需要一个完整的详情页，包含统计卡片、筛选栏、数据列表和 ticket 详情抽屉。

**参考**: `knowledge/deepseek_html_20260706_7c8a1c.html`

---

## 改动明细

### 1. `index.html` — 页面结构和详情页新增

**原因**: 将现有内容包装为 `#page-service-ops`，新增 `#page-reflow-log` 页和详情抽屉

页面结构：
- `#page-service-ops`：包装原有 Service Ops 内容
- `#page-reflow-log`：Knowledge Reflow Log 详情页，包含：
  - 面包屑导航（Engineering Ops › Knowledge Studio › Knowledge Reflow Log）
  - 页面标题 + 最后执行时间
  - 3 张统计卡片（Total Reflowed: 47 / ServiceNow: 28 / Jira: 19）
  - 筛选栏（来源下拉、日期、搜索框、Search/Reset 按钮）
  - 数据表格（Source, Ticket, Problem Summary, Solution Summary, Tags, Reflow Time, Detail）
  - 分页器
- `.drawer-overlay` + `.drawer`：右侧滑出详情抽屉（520px 宽）

### 2. `css/styles.css` — 新增约 250 行组件样式

**原因**: 新页面需要的全部样式组件

新增样式：
- `.page-panel`：页面面板切换
- `.breadcrumb`：面包屑导航
- `.reflow-stats` / `.reflow-stat-card`：3 列统计卡片网格
- `.reflow-filter-bar`：筛选栏（与 SIP 现有 filter-bar 风格一致）
- `.reflow-table`：数据表格
- `.source-badge` / `.source-dot`：ServiceNow（绿色）和 Jira（蓝色）来源标识
- `.ticket-link`：工单链接样式
- `.summary-text`：超长文本省略号截断
- `.tag`：标签胶囊
- `.detail-btn`：详情按钮
- `.pagination` / `.page-item`：分页器
- `.drawer-overlay` / `.drawer`：右侧抽屉面板 + 滑入动画
- `.drawer-body .detail-block` / `.detail-meta` / `.meta-badge`：详情内容排版
- `.btn-primary` / `.btn-secondary` / `.btn-dark`：按钮变体

### 3. `js/app.js` — 页面切换 + Reflow Log 业务逻辑

**原因**: 新增页面切换机制和 Knowledge Reflow Log 的完整交互

新增模块：
- `showPage(pageId)`：隐藏所有 `.page-panel`，显示指定页面
- `initReflowLog()`：Knowledge Reflow Log 核心逻辑
  - 10 条 mock 数据（ServiceNow + Jira ticket）
  - `renderTable(data)`：渲染数据表格，绑定 Detail 按钮事件
  - `doFilter()`：按来源和搜索关键词筛选
  - `openDrawer(ticketId)`：打开详情抽屉，展示 metadata、problem、solution、tags、vectorization status
  - `closeDrawer()`：关闭抽屉（点击 X、点击遮罩层）
  - Search/Reset 按钮绑定

修改模块：
- `initSidebar()`：叶子节点点击时调用 `showPage()` 切换到对应页面
- `initNavigation()`：点击 Engineering Ops 时切换到侧边栏选中项对应的页面；点击其他导航时显示 Service Ops 页面
- `init()`：新增 `initReflowLog()` 调用
