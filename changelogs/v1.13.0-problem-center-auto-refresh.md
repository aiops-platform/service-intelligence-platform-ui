# v1.13.0 — Problem Center 增加 5s 自动刷新

**日期**: 2026-09-07

**问题/背景**: Problem Center 只有手动 Refresh 按钮与切回页面时刷新，运维人员停留在该页时无法实时看到新
detected/变更状态的问题，需要每隔几秒轮询一次后端 `/v1/problems`。

**方案**: 复用 Reflow Log 页「仅页面可见时轮询」的既有模式（app.js:542-545，10s），Problem Center 改为
5s 静默轮询：不闪 loading 遮罩、不打断当前筛选/分页、失败静默保留旧数据；切走其他页自动暂停。

---

## 改动明细（仅 `js/app.js`，`initProblems()` 内）

### 1. 状态变量 (app.js:3616-3617)

**原因**: 需要定时器句柄与「请求在途」标志，避免慢后端时 5s 轮询与手动刷新并发堆叠。

```js
var allProblems = [];
var pcPollTimer = null;    // 5s 自动刷新定时器
var pcRefreshing = false;  // 请求在途标志：避免轮询堆叠
```

### 2. `loadServiceFilter()` 改为每次重建下拉选项 (app.js:3681-3696)

**原因**: 原实现只 append、依赖 refresh 前手动 `innerHTML=''`；静默刷新若不清空会累积重复 option。
把重建归一到 `loadServiceFilter()` 内，静默/手动路径统一去重，并保留 `currentService` 选中态。

```js
var sel = getEl('pcServiceFilter');
if (!sel) return;
sel.innerHTML = '<option value="">All Services</option>'; // 每次重建，避免静默刷新时 option 累积重复
```

### 3. `refresh(opts)` 支持静默刷新 + 在途防抖 (app.js:3966-3996)

**原因**: 5s 轮询若复用原 refresh 会每 5s 闪一次 loading 遮罩、把用户踢回第 1 页、后端异常时每 5s 弹
错误 toast。改为：`silent=true` 时不显示 loading、不重置 `currentPage`、不弹错误；`pcRefreshing` 在途
时直接跳过本次。

```js
function refresh(opts) {
    // silent=true 用于 5s 自动轮询：不闪 loading、不打断当前分页、失败不弹错（保留旧数据）
    var silent = !!(opts && opts.silent);
    if (pcRefreshing) return; // 已有请求在途（手动刷新/切页/轮询），跳过本次，避免并发堆叠
    pcRefreshing = true;
    var overlay = getEl('pcLoadingOverlay');
    if (!silent) {
        if (overlay) overlay.classList.add('visible');
        allProblems = [];
    }
    apmApi('/v1/problems?limit=500')
        .then(function (data) {
            pcRefreshing = false;
            allProblems = (data && data.items) ? data.items : [];
            if (!silent) {
                if (overlay) overlay.classList.remove('visible');
                currentPage = 0;
            }
            loadServiceFilter();
            renderKpi();
            renderTable();
        })
        .catch(function (err) {
            pcRefreshing = false;
            if (silent) return; // 轮询失败静默忽略，保留旧数据
            if (overlay) overlay.classList.remove('visible');
            window._showToast('Load problems failed: ' + err.message, 'error');
            renderKpi();
            renderTable();
        });
}
```

- 手动 Refresh 按钮 / `confirmIgnore` 后 / 切回页面（`_pageRefreshers`）仍调用无参 `refresh()`，行为不变
  （loading + 回第 1 页）。
- 静默刷新成功后保留 `currentPage`；若总页数缩小，`renderTable()` 原有的越界钳制会自动回退页码。

### 4. 初始加载 + 5s 自动刷新定时器 (app.js:4053-4059)

**原因**: 页面可见时每 5s 拉取一次；`style.display === 'none'` 判定切走后暂停，避免后台空转请求。

```js
// ── 初始加载 + 5s 自动刷新（仅当页面可见时静默轮询，切换走后自动暂停）──
refresh();
if (pcPollTimer) clearInterval(pcPollTimer);
pcPollTimer = setInterval(function () {
    var page = document.getElementById('page-problems');
    if (page && page.style.display !== 'none') refresh({ silent: true });
}, 5000);
```

## 影响范围

| 场景 | 预期 | 实际 | 状态 |
|------|------|------|------|
| 停留在 Problem Center 页 | 每 5s 静默刷新数据，无 loading 闪烁、不跳回第 1 页 | 定时器触发 `refresh({silent:true})` | OK |
| 切到其他页面 | 不再轮询（display 判定暂停） | `#page-problems` display:none → 跳过 | OK |
| 后端不可用 | 不每 5s 弹错误 toast；保留上次数据 | silent catch 直接 return | OK |
| 慢请求在途（>5s） | 不并发堆叠请求 | `pcRefreshing` 在途跳过 | OK |
| 手动 Refresh / Ignore 后 | loading + 回到第 1 页（原行为） | 无参 `refresh()` | OK |
| 服务下拉重复 | 多次刷新不累积重复 option | `loadServiceFilter()` 内每次重建 | OK |

  后 Network 不再有该请求。
