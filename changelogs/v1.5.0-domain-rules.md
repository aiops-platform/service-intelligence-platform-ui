# v1.5.0 — APM Domain Rules：域检测规则表单化配置页

**日期**: 2026-08-28

**问题/背景**: `domain_config` 是每域的检测规则（`detectors` / `suppressors` / `correlation` / `verify`），存在后端 MySQL 的 JSON 列。此前改规则只能通过 `PUT /v1/config/{domain}` 传**整个 JSON** 或直接改表，不直观易错。本次在 APM 分组下新增 **Domain Rules** 页面，把规则改为**按字段表单配置**——每个 detector/suppressor 一张卡片、params 用键值对行编辑，Save 时后端表驱动校验（非法 → 400 展示 reason）。对齐 `docs/plans/UI-domain-rules-config-plan.md` 实现计划（跨两仓库：后端补 `GET /v1/config` 域列表接口，前端全在本仓库）。

### 3. `js/app.js` — 新增 initDomainConfig() 模块 (line 4045-4455)

**原因**: 完全照搬 `initMonitorTargets` 模式（局部 `apmApi` 封装统一 `X-Tenant-Id`/可选 Bearer；卡片渲染；`_pageRefreshers` 注册；`refresh()` 进页自动加载）。核心行为：
- `refresh()` → `GET /v1/config` 填域下拉（保留当前选中）→ 自动 `loadDomain(当前域)`。
- `loadDomain(domain)` → `GET /v1/config/{domain}` 渲染卡片 + 回填 correlation/verify；并行 `GET /v1/plugins` 供插件下拉，**拉取失败回退文本输入**（不阻塞编辑）。
- 键值对行：`+ Add Param` 追加行；`collect()` 逐行 `JSON.parse`（`true`→bool、`0.9`→number、`"abc"`→string），解析失败回退原始字符串；空参数名跳过。
- Signal 输入以 `{` 开头 → `JSON.parse` 成结构化 matcher；否则按普通字符串。
- `save()` → `PUT /v1/config/{domain}` → 成功显示返回 version 并刷新域下拉；失败展示后端 reason（未配 `APM_API_KEYS` 时 401/403 引导配置）。

```js
// 插件下拉数据源：后端 /v1/plugins 返回单数键（registry.list() 的 GROUPS 键）
pluginDetectors = (data && data.detector) || [];      // 注意：非 plan 写的 detectors
pluginSuppressors = (data && data.suppressor) || [];
```

## 踩坑记录

- **plan §4/§6 写插件键为复数 `detectors`/`suppressors`，后端实际返回单数**：`GET /v1/plugins` 数据源是 `registry.list()`，其 GROUPS 键为 `collector`/`detector`/`suppressor`（`plugins/registry.py:19-22`）。实现按真实格式读 `data.detector`/`data.suppressor`，否则下拉永远为空 → 回退文本输入。
- **confirm 弹窗双模块共用**：`initDomainConfig` 与 `initMonitorTargets` 都监听 `confirmModalOverlay` 的 OK/Cancel 按钮。二者各自闭包 `_confirmCb`，`runConfirm` 里 `closeConfirm()` 先把自身 `_confirmCb` 置 null 再调用——未设置的模块 cb 为 null 直接跳过，互不干扰。
- **Signal placeholder 不能含未转义双引号**：`placeholder="cpu_usage or {"metric":"..."}"` 会截断 HTML 属性，改用 `placeholder="cpu_usage or JSON matcher"`。
- **Add 卡片不清空容器**：`addEmptyCard` 直接 append 空卡片（不调 `renderDetectors` 整容器重渲染），保留用户已编辑的未保存行；仅删除/新增后 `renumberCards()` 重排标题序号。
