# v1.2.1 — 添加 Engineering Ops 左侧导航菜单

**日期**: 2026-07-06

**问题/背景**: 点击顶部 "Engineering Ops" 导航项后需要一个左侧 sidebar 导航，包含 Knowledge Studio 下的子菜单项。

---

## 改动明细

### 1. `index.html` — 添加 sidebar 结构和 app-body 容器 (line 36-55, 435)

**原因**: 新增左侧导航面板，用 flex 容器包裹 sidebar 和 main 内容区域

```html
<!-- before -->
<main>
  <!-- Page Header -->
  ...
</main>

<!-- after -->
<div class="app-body">
  <aside class="sidebar" id="sidebar-eng-ops">
    <div class="sidebar-section-title">Engineering Ops</div>
    <div class="sidebar-nav">
      <div class="sidebar-item has-children expanded" data-toggle="knowledge-studio">
        <span class="sidebar-arrow"></span>
        <span class="sidebar-label">Knowledge Studio</span>
      </div>
      <div class="sidebar-children" id="knowledge-studio">
        <div class="sidebar-item active" data-page="knowledge-reflow-log">
          <span class="sidebar-label">Knowledge Reflow Log</span>
        </div>
        <div class="sidebar-item" data-page="rag-test-lab">
          <span class="sidebar-label">RAG Test Lab</span>
        </div>
      </div>
    </div>
  </aside>
  <main id="main-content">
    ...
  </main>
</div>
```

### 2. `css/styles.css` — sidebar 样式 (line 170-260)

**原因**: sidebar 组件样式，包括树形结构、层级缩进、展开/折叠箭头、激活态紫色左边框

关键样式：
- `.sidebar`：默认隐藏（`display: none`），点击 Engineering Ops 后通过 `.visible` 类显示
- `.sidebar-item.active`：紫色左边框（`border-left: 3px solid var(--accent-purple)`）+ 紫色背景
- `.sidebar-arrow`：CSS 三角形箭头，展开时旋转 0°，折叠时旋转 -90°
- `.sidebar-children .sidebar-item`：左侧缩进 38px 表示父子层级
- `.app-body`：flex 布局，sidebar 固定 220px 宽度

### 3. `js/app.js` — sidebar 交互逻辑 (line 8-45, 47-72)

**原因**: 新增 `initSidebar()` 函数处理 sidebar 展开/折叠和菜单项点击；扩展 `initNavigation()` 处理 sidebar 显示/隐藏

新增 `initSidebar()` 函数：
- 父节点 `.has-children` 点击展开/折叠子菜单
- 叶子节点点击高亮并更新页面标题

扩展 `initNavigation()`：
- 点击 "Engineering Ops" → 显示 sidebar，更新标题为 "Engineering Ops"
- 点击其他导航项 → 隐藏 sidebar
