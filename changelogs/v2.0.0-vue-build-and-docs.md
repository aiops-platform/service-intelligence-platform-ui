## 改动明细

### 1. `vite.config.js` — 抽出 `proxy` 常量，dev 与 preview 共用

**原因**：Vite 的 preview server **不继承 `server.proxy`**。只配 server 的话
`npm run preview` 会连不上后端、页面看着像坏了（外壳在、数据全空），而 README 又让用户跑 preview。

```diff
- server: { port: 5173, proxy: { …内联… } },
+ const proxy = { '/api/sip-aiops': …, '/agentflow': … }
+ server:  { port: 5173, proxy },
+ preview: { port: 4173, proxy },
```

### 2. `README.md` — 重写

- 快速开始（`npm install` / `dev` / `build` / `preview`）
- 代理对照表 + 「不要起在 8080」的提醒
- **生产 nginx 片段**（`try_files` 回退 + 两条 `proxy_pass`），并给出无 nginx 时的兜底
  （换 `createWebHashHistory`，一行）
- 明确「后端没起也能看界面」的预期行为
- 明确不在范围的两项：APM/KB 相关视图、`engineering-ops-standalone.html`
- 保留原有的 "Monitor Targets — Manual Run" 说明，补注其 DOM/脚本现在的位置

### 3. `CLAUDE.md` — 架构段从「纯静态」改写为「双世界」

原文断言「无构建工具 / 无框架 / 无路由 / 无 API 层」、「数据全部硬编码（19 个应用行）」、
「`assets/` 空目录」—— 对新代码全部不再成立（且后两条在改造前就已过期，`assets/` 根本不存在）。

新版内容：

- **双世界对照表**（Vue 世界 / 遗留世界的 DOM 归属、样式共用）
- **接缝清单**（7 个 `window.__SIP_*` 各自的作用与「独立打开旧 index.html 时不生效」的保证）
- **迁移一个新视图的 5 步 checklists** —— 其中特意标明 `MIGRATED` 与 `VIEW_COMPONENTS`
  **必须同时改**，否则出现「组件渲染了但 legacy 面板没隐藏」的双显
- **跨域**（`src/` 零绝对 URL 的不变式 + base 三级回退 + 未迁移视图的不对称是有意保留）
- **样式**（不 scoped、逐字沿用 class；**并记下 `#bsZoomFit` 那个坑**：样式表也是 id 的消费方）
- **渲染约定**（已迁移视图禁拼串；唯一允许 v-html 的位置；模态保留拼串的理由与两条约束）
- 版本号 → `v2.0.0`
