# v1.4.9 — Edit 态点 Reset 恢复该条记录原始内容（不再清空成 New）

**日期**: 2026-08-27

**问题/背景**: Monitor Target 弹窗点 Edit 正常回填，但点 **Reset** 会无条件把表单清成全新的 New 空表单。需求：**编辑态下 Reset 应恢复这条记录原本保存的内容**（丢弃未保存的修改），而不是清空成 New。

---

## 改动明细

### `js/app.js` — `resetForm(silent)` 编辑态分支

**原因**: Reset 的语义应区分「编辑中丢弃修改」与「新建清空」。改动点：

```js
function resetForm(silent) {
    if (currentTarget) {
        // 编辑态：Reset 恢复该条记录已保存的内容（丢弃未保存的修改）
        fillForm(currentTarget);
        if (!silent) window._showToast('Form reset to saved values', 'info');
        return;
    }
    // New 态：保持原有清空逻辑不变
    currentTarget = null;
    getEl('apmService').value = '';
    ...
    if (!silent) window._showToast('Form reset to New', 'info');
}
```

`fillForm(target)` 会重填所有字段、把 `currentTarget` 置回该记录并刷新表单状态提示（`Editing X`），天然符合「恢复原始内容」语义；New 态路径完全不动。

---

## 踩坑记录

- **`currentTarget` 就是「已保存内容」**：Edit 时 `fillForm(t)` 把列表行（服务端已保存状态）存入 `currentTarget`，Reset 直接 `fillForm(currentTarget)` 即恢复，无需再请求后端。
- **New 态 Reset 行为不变**：`currentTarget` 为 null 时仍走原清空逻辑（`New Target` + 「Form reset to New」），不影响 New 按钮。

## 影响范围

| 场景 | 预期 | 实际 | 状态 |
|------|------|------|------|
| Edit 后修改字段，点 Reset | 表单恢复为该记录原始内容，状态提示 `Editing X` | 已改，待浏览器确认 | 待验证 |
| Edit 后直接点 Reset | 表单回到原始内容（无变化） | 同上 | 待验证 |
| New 态点 Reset | 清空成 New（原行为不变） | 未动 | OK |
| New 按钮 | 仍开空表单 New Target | `resetForm(true)` 走 New 分支 | OK |
