# v1.2.1 — Approval Center 页面

**日期**: 2026-07-07

**问题/背景**: Service Ops > Ticket Workspace > Approval Center 需要专属页面，展示 RAG 解决方案审批工作流（L1→L2→L3→Human 多层 Agent 协作），参考 `knowledge/deepseek_html_20260707_34140c.html` 设计。列表使用 Agent Tasks 表格风格，详情使用模态弹窗。

---

## 改动明细

### 1. `index.html` — 新增 `#page-approval-center` + 审批 Modal

页面组成：
- 5 个 KPI 卡片（Pending / Approved / Rejected / Escalated / Avg Confidence）
- 搜索工具栏 + 筛选芯片（All / Pending / Approved / Rejected / Escalated）
- 8 列表格（RAG ID / Ticket / Title / Status / Agent / Confidence / Source / Review 按钮）
- 模态弹窗 `#apModalOverlay`：决策链路（Chain Steps）+ 详情网格 + 相似案例 + 执行日志 + 审批操作按钮

### 2. `css/styles.css` — Approval Center 专属样式

新增：
- `.ap-status` — 四种状态标签（pending/approved/rejected/escalated）
- `.ap-agent-tag` — Agent 层级标签（L1/L2/L3/Human）
- `.ap-source-tag` — 来源标签（ServiceNow/Jira）
- `.modal-overlay` / `.modal-box` — 模态弹窗（带 backdrop blur + slideUp 动画）
- `.chain-steps` / `.chain-step` — 决策链路组件
- `.detail-grid` / `.detail-item` — 弹窗内 2 列详情网格
- `.case-list` — 相似案例列表
- `.modal-log-panel` — 弹窗内执行日志面板
- `.approval-actions` / `.btn-ap` — 审批操作按钮（approve/reject/escalate）

### 3. `js/app.js` — 新增 `initApprovalCenter()` 函数 + 接入 init()

`initApprovalCenter()`：
- 5 条 mock RAG 建议数据（RAG-001 ~ RAG-005），覆盖 4 种状态
- 每条含：决策链路（4 步）、相似案例（2-3 个）、执行日志（5-6 条）
- `renderAPTable()` — 表格渲染
- 搜索 + 状态筛选
- `openAPModal()` — 打开审批模态弹窗，展示完整决策追溯：
  - 决策链路（L1 分类 → L2 RAG 检索 → L3 方案生成 → 人工审批）
  - 工单描述 + 推荐方案
  - RAG 检索到的历史相似案例（含相似度百分比）
  - L1→L2→L3→Human 执行日志
  - 审批操作：Approve（回写关单）/ Reject（转人工）/ Escalate（升级 L3）
- 审批后自动更新统计和列表状态

`init()` 中新增 `initApprovalCenter()` 调用。

### 4. sidebar 路由更新

`approval-center` → `showPage('page-approval-center')`
