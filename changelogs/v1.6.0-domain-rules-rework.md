# v1.6.0 — Domain Rules 重构为 Monitor Targets 同款流程（列表 + 模态框 + New/Edit/Delete）

**日期**: 2026-08-28

**问题/背景**: v1.5.0 的 Domain Rules 是「域下拉 + Load/Save + 页内卡片直编」——只能改已有域，**没有域列表、没有 New Domain 从零创建、没有 Delete**。本次把页面重构为与 Monitor Targets 同款流程：**底部域列表 + 行内 Edit/Delete + New Domain 按钮，New/Edit 打开模态框编辑该域配置**。配套后端补了缺失的 `DELETE /v1/config/{domain}`（含引用守卫），否则 Delete 无接口可用。

---

## 改动明细

### 1. 后端 `aiops-apm-anomaly-detector` — `DELETE /v1/config/{domain}` + store delete（跨仓库）

**原因**: Domain Rules 前端要 Delete 对齐 Monitor Targets，但后端没有删除端点、`DomainConfigStore` 无 delete 方法。且 `build_context` 对缺失域抛 `ValueError("no domain config for domain=...")`（`pipeline/context.py`）——删掉仍被 enabled `monitor_target` 引用的域会让该目标调度直接失败，必须加引用守卫。

- `src/aiops_apm/storage/domain_config.py`：`DomainConfigStore` ABC 新增 `delete(tenant_id, domain)`；`InMemoryDomainConfigStore` 从 `_rows` 移除匹配行；`MySQLDomainConfigStore` 执行 `DELETE FROM domain_config WHERE tenant_id=%s AND domain=%s`（均先校验 tenant_id 非空）。
- `src/aiops_apm/router/config.py`：新增 `@router.delete("/{domain}", status_code=204)`（admin）——先查存在（404），再用 `load_all_targets`（只返回 enabled 且未删的目标）查引用，被引用 → `CONFIG_ERROR`（400）`"still referenced by enabled targets ..."`；否则 `store.delete` + 审计。
- 测试：`tests/test_config_api.py` +4（删自定义域 / 404 / 被引用 400 / 列表移除）、`tests/test_domain_config.py` +2（store delete 移除行 + tenant 校验）。后端 `make lint test` 413 passed 全绿。

### 2. `index.html` — 页面板改为列表 + 新增模态框

**原因**: 对齐 Monitor Targets 结构（`page-monitor-targets` 的 toolbar + `reflow-table` + modal，index.html:1163-1368）。

- 重写 `page-domain-config` 面板：breadcrumb/page-header 保留；工具栏换为 `dcSearch` + `dcNewBtn`（New Domain）；新增列表区 `dcTableContainer`（`dcLoadingOverlay` + `dcTableBody`：Domain/Enabled/Version/Actions + `dcRowCount`）。**移除** `dcDomainSelect`/`dcLoadBtn`/`dcSaveBtn`/`dcStatus` 与页内 DETECTORS/SUPPRESSORS/CORRELATION 区块。
- 新增模态框 `dcModalOverlay`（照搬 `apmModalOverlay` 结构）：`dcFormHint`（New Domain / Editing X）+ `dcDomainName`（域名输入，`maxlength=32` + `pattern="[a-zA-Z0-9_-]+"`）+ DETECTORS/SUPPRESSORS/CORRELATION 区块（容器 id 沿用 `dcDetectors`/`dcSuppressors`，卡片渲染代码零改动）+ `dcSaveBtn`/`dcResetBtn`。

### 3. `js/app.js` — 重构 `initDomainConfig()` 为列表 + 模态框流程

**原因**: 流程从「选域→页内改」变成「列表→点行→模态框改」。卡片渲染/键值对行/collect/fillStatic 全部保留。

- 新增：`openDcModal/closeDcModal`（`.open` toggle，同 `openModal/closeModal`）、`loadPlugins`（插件下拉预载，失败回退文本输入）、`renderList`（按 `dcSearch` 过滤 + 空态提示）、`refresh`（`GET /v1/config` → `renderList`）、`onListAction`（Edit → 模态框；Delete → confirm）、`newDomain`（空表单 + 域名可输入）、`editDomain`（`GET /v1/config/{domain}` + 并行 `loadPlugins` → 渲染卡片 + `fillStatic`；域名 `readOnly` 锁定）、`save`（校验 `^[a-zA-Z0-9_-]{1,32}$` → `PUT` → 关框 + toast + 刷新）、`deleteDomain`（`DELETE` → toast + 刷新；400 展示后端 reason）、`resetForm`（Edit 态恢复 `currentDomainData`；New 态清空）。
- **移除**：`setStatus`/`dcDomainSelect`/`dcLoadBtn`/`dcStatus` 相关代码，状态反馈全部改用 `window._showToast`（同 Monitor Targets）。
- wiring 对齐：`dcNewBtn`/`dcSaveBtn`/`dcResetBtn`/`dcModalClose`/`dcModalOverlay` 点击关 + Escape 关 + `dcTableBody` 委托 + `dcSearch` 防抖 200ms。

### 4. `css/styles.css` — 模态框宽 override + 清理

**原因**: 复用 `.ap-modal*`/`.reflow-table`/`.apm-badge`/`.si-loading-overlay`/`.rule-card*`/`.kv-*` 后仅需补模态框宽化。

- 新增 `#dcModalOverlay .ap-modal`（1200px + `calc(100vh - 120px)`，复制 `#apmModalOverlay .ap-modal`）+ `#dcModalOverlay` 对齐。
- 移除 `.dc-label`/`.dc-status`/`.dc-status-ok`/`.dc-status-err`（dcStatus 弃用）。

## 踩坑记录

- **`GET /v1/config/{domain}` 详情响应无 `enabled` 键**：只有列表 `GET /v1/config` 带 enabled。列表页数据源用列表接口即可；详情接口只供编辑回填 config/version，不依赖 enabled。
- **`PUT /v1/config/{domain}` body 无 `domain`/`enabled`**：域名走 URL 路径、enabled 由 upsert 强制 True。前端 Save 组装 body 只含 detectors/suppressors/correlation/verify；新建域名从 `dcDomainName` 取后拼进 URL。
- **Delete 引用守卫语义**：`load_all_targets` 只返回 `enabled=1 AND deleted=0` 的目标——禁/删的目标不再调度，不算引用，可放心删域。前端 400 时 toast 直接展示后端 reason（含 target_id），引导先处理引用目标。
- **每次路由调用新建 `DomainConfigLoader`**：loader 缓存是实例级，删除后不会污染后续 load（无跨请求缓存失效问题）。
