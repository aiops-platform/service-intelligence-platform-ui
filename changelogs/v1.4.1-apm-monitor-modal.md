# v1.4.1 — Monitor Targets 表单收进模态框

**日期**: 2026-08-27

**问题/背景**: v1.3.0/v1.4.0 中 Monitor Targets 页面是「表单 + Test/Run 结果 + 列表」自上而下平铺。用户希望列表成为主内容，新增/编辑走弹窗：点 **New** 或列表行 **Edit/Test/Run** 时弹出模态框，框内含完整表单（Service/Signal Type/…/Time Params）、操作按钮（Save / Connectivity Test / Manual Run / Reset）与 Test/Run 结果区——不再与列表平铺在一页。

---

## 改动明细

### 1. `index.html` — 页面主体改为「列表为主内容」，表单 + 结果迁入模态框 (line 1160-1205、1207-1306)

**原因**: 页面 div 内只保留面包屑/标题 + Targets List（筛选栏 + 表格）；原表单卡片与 Test/Run 结果区整体移入 `#apmModalOverlay`（复用既有 `.ap-modal-overlay`/`.ap-modal` 模态框模式，含 `ap-modal-header` + `ap-modal-body`）。模态框放在 `#page-monitor-targets` 外——因为 `.page-panel` 隐藏页为 `display:none`，若弹窗留在页面内会被一起隐藏。表单字段、按钮、结果区 id 全部保留，JS 零改动即可继续读写。

```html
<!-- before: 页面内平铺 form-card + result + 列表 -->
<div id="page-monitor-targets" class="page-panel">
  <div class="apm-form-card">...表单...</div>
  <details class="apm-result">...</details>
  <div class="reflow-filter-bar">...</div>
  <div class="table-container">...</div>
</div>

<!-- after: 列表为主内容，弹窗独立于页面外 -->
<div id="page-monitor-targets" class="page-panel">
  <div class="reflow-filter-bar">... New 按钮 ...</div>
  <div class="table-container">...</div>
</div>
<div class="ap-modal-overlay" id="apmModalOverlay"> <!-- position:fixed，不受页面 display:none 影响 -->
  <div class="ap-modal">
    <div class="ap-modal-header"><h3 id="apmFormTitle">... <span id="apmFormHint">New Target</span></h3><button id="apmModalClose">&times;</button></div>
    <div class="ap-modal-body">
      <div class="apm-form-grid">... 全部字段 ...</div>
      <div class="apm-form-actions">Save / Connectivity Test / Manual Run / Reset</div>
      <details class="apm-result" id="apmResult">... Test/Run 结果 ...</details>
    </div>
  </div>
</div>
```

### 2. `js/app.js` — 弹窗开关 + 打开/关闭接线 (line 3702-3708、3967-3977、4007-4010、4025-4031)

**原因**: New 按钮与列表行 Edit/Test/Run 均改为先 `openModal()` 再 `resetForm()`/`fillForm()`；关闭支持标题栏 X、点击遮罩（非弹窗本身）、Escape 键。

```js
function openModal()  { getEl('apmModalOverlay').classList.add('open'); }
function closeModal() { getEl('apmModalOverlay').classList.remove('open'); }

// New 按钮：重置表单 + 打开弹窗
getEl('apmNewBtn').addEventListener('click', function () { resetForm(); openModal(); });

// 列表行 Edit/Test/Run：打开弹窗再回填（Test/Run 会立即执行）
if (act === 'edit') { openModal(); fillForm(t); }
else if (act === 'test') { openModal(); fillForm(t); connectivityTest(); }
else if (act === 'run')  { openModal(); fillForm(t); manualRun(); }

// 关闭：X / 遮罩 / Escape
getEl('apmModalClose').addEventListener('click', closeModal);
getEl('apmModalOverlay').addEventListener('click', function (e) { if (e.target === this) closeModal(); });
document.addEventListener('keydown', function (e) {
    if (e.key === 'Escape' && getEl('apmModalOverlay').classList.contains('open')) closeModal();
});
```

### 3. `js/app.js` — `showPage()` 统一关闭弹窗 (line 48-51)

**原因**: 模态框为 `position: fixed`，若弹窗打开时切换页面，遮罩会残留盖住新页面；在 `showPage()` 里切页即移除 `open`。

```js
// 关闭 Monitor Target 模态框（fixed 遮罩若残留会盖住其他页面）
var apmModal = document.getElementById('apmModalOverlay');
if (apmModal) apmModal.classList.remove('open');
```

### 4. `css/styles.css` — 宽模态框样式；移除不再使用的 `.apm-form-card`/`.apm-form-header` (line 4547-4555)

**原因**: 复用 `.ap-modal` 模态框基础样式，`#apmModalOverlay` 放大到 1200px 宽；改为固定高度 `calc(100vh - 120px)`，模态框始终占满「视口高 − 上下各 60px」——顶部 `header` 为 `position: fixed; height: 52px`，60px 在其下方留出 8px 空隙（36px 会与菜单栏重叠，已实测修正），底部与顶部距离恒等（各 60px，不再依赖内容高度居中）；内容超高时由 `.ap-modal-body` 内部 `overflow-y: auto` 滚动；表单卡片类因 HTML 不再引用而删除（避免死代码）。

```css
#apmModalOverlay .ap-modal { max-width: 1200px; height: calc(100vh - 120px); max-height: calc(100vh - 120px); }
#apmModalOverlay { align-items: center; padding: 60px 24px; }
```

## 踩坑记录

- **模态框必须放在页面 div 外**：`.page-panel` 隐藏页 `display:none`，弹窗若留在页面内会被一起隐藏；因 `position: fixed` 不受 DOM 位置影响，移到 `#page-monitor-targets` 后即可正常显示。
- **遮罩残留**：`showPage()` 切页不关弹窗 → 遮罩盖住新页面；需在 `showPage` 全局移除 `open`，而非只依赖本页 refresher（本页 refresher 只在切回本页时触发）。
- **id 唯一性核对**：表单字段从页面迁入弹窗后，逐一核对 31 个 `id="apm*"` 均唯一（`grep -c` 全为 1），避免重复 id 导致 JS 读错元素。
