# v2.2.1 — 隐藏 Service Ops › Ticket Workspace 下的 Approval Center 与 L1 Automation

**日期**: 2026-09-17

**需求**: Service Ops 域侧边栏 `Ticket Workspace` 分组里，**Approval Center** 与
**L1 Automation** 两个入口不再展示，该分组只保留 `Ticket Inbox`。

---

## 改动明细

### 1. `src/router/nav.js` — `ticket-workspace-svc` 分组摘掉两个叶子 (line 96-114)

**原因**: `NAV` 是导航的唯一真源，侧边栏（`SidebarGroup.vue`）与路由表
（`flattenItems()` → `src/router/index.js:161`）都从它派生。所以**摘叶子一处，菜单与路由一起收口**。

```js
// before
items: [
  { slug: 'tickets', label: 'Ticket Inbox' },
  { slug: 'approval-center', label: 'Approval Center' },
  { slug: 'l1-automation', label: 'L1 Automation' },
],

// after
items: [{ slug: 'tickets', label: 'Ticket Inbox' }],
```

并在分组上方补了注释块，写明**只摘导航不删页面**与两行恢复代码 —— 与上面
Business Ops 那次摘侧边栏（line 72）保持同一套记法。

**刻意没有动的东西**（恢复时一个都不用碰）：

| 位置 | 内容 |
|---|---|
| `src/legacy/legacy-panels.html` | `#page-l1-automation`（:626）、`#page-approval-center`（:700） |
| `js/app.js` | `initNavigation` 的 `l1-automation` / `approval-center` 分支（:142-145、:644-645） |
| `src/router/nav.js` | `PANEL_ID` 两条映射（:25-26） |

### 2. `README.md` — 新增「Ticket Workspace — Approval Center / L1 Automation（已隐藏）」章节

**原因**: 这是一次**看起来像页面丢了**的改动 —— 与 v2.2.1 修的那个 APM bug 症状一模一样
（点菜单页面不切换）。必须留下书面记录，否则下一个人会当成 bug 去查。
章节格式对齐既有的「Monitor Targets — Manual Run（暂移除）」：现状 + 未删清单 + 恢复方式。

## 踩坑记录

- **差点去改 `js/app.js` 的 `initNavigation`**：那两处 `else if (page === 'l1-automation')`
  看着像必须一起删的「残留」。实际它们在嵌入模式下**根本不会被调用**
  （`__SIP_LEGACY_ROOT` 存在时整个 `initNavigation` 被跳过），删了反而会弄坏
  独立打开旧 `index.html` 的入口。留着是对的。
- **没有新增 `hidden` 标志位**：另一个思路是给 item 加 `hidden: true` 再在两处消费点过滤。
  没走这条路 —— `flattenItems()` + 侧边栏渲染已经是两个消费点，加标志位等于引入
  第三套「可见性」语义；而「从 `NAV` 摘掉」本身就已经同时表达了两者，且与
  Business Ops 的先例一致。
