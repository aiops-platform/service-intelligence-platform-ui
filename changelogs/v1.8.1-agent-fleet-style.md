# v1.8.1 — Agent Registry 样式调整：移除工具 chips、分组各自成盒、卡片收紧

**日期**: 2026-08-31

**问题/背景**: Agent Registry 页面的工具筛选 chips 占空间且语义与 Reset 重复；各流水线分组（stage）虽已拉开间距但仍挤在同一个容器视觉里，用户希望每个 stage 成为独立区块；agent 卡片间距偏大，舰队感不够紧凑。

---

## 改动明细

### 1. `js/app.js` — 移除工具 chips 相关逻辑 (app.js:5014, app.js:5059, app.js:5087, app.js:5169)

**原因**: 工具筛选 chips 整组去掉（含此前保留的 "All Tools" 与数据派生 chips），搜索框 + Reset 已覆盖筛选/恢复全部语义。清理全部相关状态与函数。

```js
// before
var currentToolFilter = '';
// filteredAgents() 内有 currentToolFilter 过滤分支
// renderToolFilters() 渲染 chips 并绑定点击
// after
var currentSearch = '';   // 仅保留搜索
// filteredAgents() 仅按 name/description 搜索
// renderToolFilters() 删除，renderFleet() 不再调用
```

### 2. `index.html` — 移除 chips 容器 (index.html:1392)

**原因**: 工具栏只保留搜索框 + Reset，`#agToolFilters` 容器删除。

```html
<!-- before -->
<input type="text" ... id="agSearch" style="flex:1;min-width:200px;">
<div id="agToolFilters" ...></div>
<button class="btn btn-outline" id="agResetBtn">Reset</button>
<!-- after -->
<input type="text" ... id="agSearch" style="flex:1;min-width:200px;">
<button class="btn btn-outline" id="agResetBtn">Reset</button>
```

### 3. `index.html` + `js/app.js` — 移除 API 源地址标签 (index.html:1361, app.js:5039)

**原因**: 页面头部 Refresh 按钮旁的 `http://localhost:8000` 源地址提示（`#agSourceLabel`）是调试信息，用户不需要。删除该 span 及其在 `loadAgents()` 中的赋值。

```html
<!-- before -->
<button ...>Refresh</button>
<span class="text-secondary text-sm" id="agSourceLabel"></span>
<!-- after -->
<button ...>Refresh</button>
```

### 4. `css/styles.css` — 移除整片舰队白盒、每组各自白卡、卡片收紧 (styles.css:4931, styles.css:4960)

**原因**: 用户反馈的"stage 之间的白色 div"其实是 `#agFleetContainer`（`.table-container`）把整个舰队包成了一个白色大盒子。处理：去掉该大盒子（`#agFleetContainer` 透明无边框），同时每组 stage 各自包一个白卡（白底/描边/圆角/内边距），stage 与 stage 以独立白卡边界分隔。

```css
/* 去掉整片舰队白盒 */
#agFleetContainer {
    background: transparent;
    border: none;
    border-radius: 0;
}
/* 每组各自成白卡 */
.agent-group-section {
    margin-bottom: 16px;
    padding: 14px 16px;
    background: var(--bg-white);
    border: 1px solid var(--border-color);
    border-radius: 8px;
}
```

> 过程回退：曾先移除每组白卡改纯间距，但整片 `#agFleetContainer` 白盒仍在；确认用户指的白 div 是容器后，改为「去掉容器白盒 + 每组白卡」。
