# v2.2.15 — CMDB 实体图谱页去掉左侧导航栏（页面全宽）

**日期**: 2026-09-20

**需求/背景**: CMDB 实体图谱页不应显示左侧导航栏。

**根因**: `/cmdb` **不属于任何导航域**（`nav.js` 里没有它），但 `App.vue` 的

```js
const activeKey = computed(() => route.meta.domainKey ?? navKeyOf(activeSlug.value) ?? 'service-ops')
```

末尾那个 `?? 'service-ops'` **兜底**会把域外路由误判成 Service Ops，
于是 Service Ops 的侧边栏被挂到了一个跟它无关的页面上。

代码里本来有同类处理的先例（`slugDomainKey` 只用 `navKeyOf`、绕开兜底），
但那**只挡住了折叠把手、没挡侧边栏本身**——把手没了、导航还在，反而更怪。

---

## 改动明细

### 1. `src/router/index.js` — `/cmdb` 声明 `meta.standalone: true` (47)

**原因**: 让"这页不属于任何导航域"成为**显式声明**，而不是靠隐式推断。

### 2. `src/App.vue` — `showSidebar` 尊重 standalone (67)

```js
const isStandalonePage = computed(() => route.meta.standalone === true)
const showSidebar = computed(
  () => !isStandalonePage.value && !!activeSidebar.value && !(sidebarCollapsible.value && collapsed.value),
)
```

**为什么用声明的 meta 而不是按路径判**：路径散在 router 里，加了新的独立页就得
回来改这里，很容易漏——`/runs/:runId` 就是靠"`navKeyOf` 恰好返回 null"这种**隐式**
条件才没显示把手的。

---

## 影响范围

| 路由 | 预期 | 实际 | 状态 |
|------|------|------|------|
| `/cmdb` | 无侧栏、页面全宽 | 截图确认 | OK |
| `/runs/...` | 侧栏保留 | 截图确认（Ticket Workspace / Observability 都在） | OK |
| `/service-ops` | 既有收起态 | 不变（原设计即默认收起） | OK |
| 生产构建 | 通过 | `npm run build` ✓ | OK |

## 顺带记一笔（未修）

`/runs/:runId` 显示侧栏、但**不显示折叠把手**（域判定绕开了兜底，把手被挡在域外）。
能用，但"有导航却收不起来"不一致——本轮没动它。
