# v2.2.10 — 点击节点时，从它出去的连线有流动效果到目标节点

**日期**: 2026-09-20

**需求/背景**: 在 Run Detail（与 Bug Solve）的 workflow 图上，点击某个节点时，
**从这个节点出去的线**要有"流动"观感，一路流到目标节点。

用虚线滚动实现：`stroke-dasharray` + 动画 `stroke-dashoffset`。
`dashoffset` 取**负值**——SVG 的 dash 前进方向就是路径方向，而本引擎生成的 path
一律从源节点画向目标节点，所以负偏移即"朝着目标流"；写成正值会变成倒吸。

---

## 改动明细

### 1. `src/components/graph/useGraphCanvas.js` — 主干/分支带归属标记 (248–262)

**原因**: 点击时要能按节点找回"属于它的线"。原先所有 path 都是光秃秃的 `bs-edge`。

```js
// 主干
`<path class="bs-edge" data-out="${n.id}" …/>`   // 出主干
`<path class="bs-edge" data-in="${n.id}" …/>`    // 入主干
// 分支
`<path class="bs-edge" data-from="${e.from}" data-to="${e.to}" …/>`
```

### 2. `src/components/graph/useGraphCanvas.js` — `highlightFlow` / `clearFlow` (332 / 308)

**原因**: 实现流动高亮。

**要覆盖三段才"看起来流到了目标"**：

| 段 | 选择器 | 少了它会怎样 |
|---|---|---|
| 出主干 | `[data-out=<nid>]` | 源头没起点 |
| 分支 | `[data-from=<nid>]` | 流不出去 |
| **各目标的入主干** | `[data-in=<to>]` | **流动在目标上方就断了** |

第三段最容易漏——分支本身只画到"目标上方"，最后一截竖线是**目标节点的入主干**。

### 3. `src/components/graph/useGraphCanvas.js` — 高亮箭头 (238) + 重放 (290)

**原因** 之一：箭头要跟线同色，否则线变蓝了箭头还是灰的。
在 `<defs>` 里加一个 `${markerId}Flow` 蓝色箭头，高亮时替换 `marker-end`，
并**记住原值**（`data-flow-marker`）以便还原。

**原因** 之二（**这个不修会漏**）：宿主是**轮询驱动**的，
`renderGraph` 每次数据变化都整段重写 `innerHTML`，**高亮会被抹掉**——
点击后流动几秒就自己没了。故记住 `flowNode`，在 render 末尾重放。

### 4. `css/styles.css` — `.bs-edge-flow` + `bsEdgeFlow` (6188)

```css
.bs-edge-flow {
    stroke: var(--accent-blue);
    stroke-width: 2;
    stroke-dasharray: 6 6;
    animation: bsEdgeFlow 0.7s linear infinite;
}
@keyframes bsEdgeFlow { to { stroke-dashoffset: -12; } }
```

并加 `@media (prefers-reduced-motion: reduce)` 降级：去掉滚动，只留高亮色。

## 踩坑记录

### 轮询会把高亮冲掉（已修，见改动 3）

宿主 `RunDetailView` 用 `watch(() => runData.value?.nodes, …, {deep:true})` 驱动重绘，
数据一更新就重新 `render()` → `innerHTML` 整段重写 → **类名全丢**。
表现是"点了节点会流动，几秒后自己停了"，很容易被当成动画没生效。

写了个探针验证：点击后 `rerender` 再数一次 `.bs-edge-flow` 的个数 ——
修复前会是 `click=15 rerender=0`，现在是 `click=15 rerender=15`。

### 色值写了两处

SVG 里 marker 的 `fill` **取不到 CSS 变量**，所以 `FLOW_COLOR = '#3b82f6'`
在 JS 里写死了一份，与 CSS 的 `var(--accent-blue)` 是同一个值。
**改一处要改两处**，两边注释里都标了。
