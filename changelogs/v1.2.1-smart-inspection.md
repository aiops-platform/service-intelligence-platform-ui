# v1.2.1 — Smart Inspection 页面

**日期**: 2026-07-07

**问题/背景**: Engineering Ops > Ticket Workspace > Smart Inspection 需要专属页面，展示应用服务智能检测指标（CPU/Memory/Disk），参考 `knowledge/deepseek_html_20260707_41df8b.html` 设计。使用 KPI 统计卡片 + 列表 + 详情抽屉。

---

## 改动明细

### 1. `index.html` — 新增 `#page-smart-inspection` 页面

页面组成：
- Breadcrumb: Engineering Ops > Ticket Workspace > Smart Inspection
- ML Baseline 徽章（紫色，脉冲动画）
- 5 个 KPI 卡片（Total Services / Healthy / Warning / Critical / Total Alerts）
- 搜索工具栏 + 筛选芯片（All / Healthy / Warning / Critical）
- 8 列表格（Service Name / Type / CPU% / Memory% / Disk% / Alerts / Status / Detail 按钮）
- 每行含进度条 + 基线值显示

### 2. `css/styles.css` — Smart Inspection 专属样式

新增：
- `.si-ml-badge` / `.si-ml-dot` — ML Baseline 徽章（紫色脉冲动画）
- `.si-metric-cell` / `.si-metric-val` / `.si-metric-bar` / `.si-metric-fill` — 指标进度条组件（normal/warning/critical 三色）
- `.si-metric-baseline` — 基线参考值文字
- `.si-service-cell` / `.si-service-icon` / `.si-service-name` / `.si-service-type` — 服务名称单元格
- `.si-status` — 三种状态标签（healthy/warning/critical）
- `.si-alert-badge` — 警报计数徽章（has-alerts 脉冲样式）
- `#siTableBody tr.row-warning` / `tr.row-critical` — 行高亮（左边框着色）
- `.si-detail-metrics` / `.si-detail-metric` — 详情抽屉内 3 列指标展示

### 3. `js/app.js` — 新增 `initSmartInspection()` 函数 + 接入 init()

`initSmartInspection()`：
- 7 条 mock 服务数据（Customer Service / Insurance Service / Payment Service / Auth Service / Order Service / Notification Service / Report Service）
- 每条含 CPU/Memory/Disk 当前值 + 基线值 + 状态 + 警报计数
- `renderSITable()` — 表格渲染，含进度条、基线值、状态徽章、警报计数
- 搜索 + 状态筛选（Healthy/Warning/Critical）
- `openSIDetail()` — 打开详情抽屉，展示 3 列指标面板 + 服务信息网格 + ML Baseline 参考分析
- `updateSIStats()` — 统计 KPI 卡片数据

`init()` 中新增 `initSmartInspection()` 调用。

### 4. sidebar 路由更新

`smart-inspection` → `showPage('page-smart-inspection')`
