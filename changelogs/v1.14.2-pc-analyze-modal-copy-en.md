# v1.14.2 — Problem Center Analyze 弹框文案统一英文

**日期**: 2026-09-07

**问题/背景**: Analyze 弹框（`#pcAnalyzeOverlay`）整体是英文 UI（标题 "Analyze Problem"、info 行、Cancel/Analyze 按钮），
但个别文案残留中文：未选 workflow 点 Analyze 的 toast、下拉占位、流程加载失败提示。用户要求弹框文案统一使用英文。

**方案**: 仅改 `js/app.js` 中 Analyze 弹框（`initProblems()` 内）三处字面量。Bug Solve 页对应字符串不动。

---

## 改动明细

### 1. `js/app.js` — Analyze 弹框文案改英文 (app.js:3978/3997/4024)

**原因**: 弹框为英文 UI，三处中文文案与其不一致；用户点 Analyze 未选 workflow 时弹出的提醒应为英文。

```js
// 3978 下拉占位（fillAnalyzeWorkflows）
'<option value="">-- Select a saved workflow --</option>'
// 3997 流程加载失败（loadAnalyzeWorkflows）
window._showToast('Failed to load workflows: ' + (err && err.message ? err.message : 'network error'), 'error');
// 4024 未选 workflow 点 Analyze（confirmAnalyze）
if (!workflowId) { window._showToast('Please select a workflow first', 'error'); return; }
```

- 仅命中 `initProblems()` 的 Analyze 弹框代码：3978 用函数体上下文精确定位，未误改 Bug Solve 页同款下拉占位
  （app.js:5807）；5846 的 `showError('请先选择已保存流程')` 属 Bug Solve 页，保持中文不变。
- 其余弹框 / 页面文案零改动。
