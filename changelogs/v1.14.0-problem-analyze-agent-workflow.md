# v1.14.0 — Problem Center Analyze：选 Workflow 发起 agent 工作流分析

**日期**: 2026-09-07

**问题/背景**: Problem Center 中 `pending` 状态问题的 **Analyze** 按钮原本是空操作（行操作委托只处理了
`detail`/`ignore`，没有 `analyze` 分支）。需求：点 Analyze → 弹出**选 Workflow 弹框**（复用 Bug Solve
页的 `/workflows` 下拉）→ 选好点 Analyze → 弹框关闭 → 请求 anomaly-detector 新接口
`POST /v1/problems/{record_id}/analyze`：按选中 workflow 把该问题映射成一张**平铺 ServiceNow 风格 ticket**，
`POST {workflow_id, ticket}` 到 agentflow（multi-agent-workflow）`POST /run` 启动 agent run → 成功后该问题
`state` 翻成 `in_progress`（列表行 Analyze/Ignore 按钮消失，5s 轮询同步）。

**方案**: SIP 前端只负责「弹框选流程 + 调用后端 analyze 接口」，不做乐观更新（以后端为准，刷新 + 5s 轮询兜底）。
后端部分（Settings 新增 `bug_solve_base_url`、`mark_in_progress` 原子单翻、analyze 路由与 ticket 平铺映射、
`CONFLICT/UPSTREAM` 错误码）在 `aiops-apm-anomaly-detector` 仓库实现，本 changelog 聚焦 SIP 改动；anomaly-detector
无 changelog 约定，仅代码+测试。

### 4. `js/app.js` — Analyze 弹框逻辑函数 (app.js:3975-4041)

**原因**: 懒加载 `/workflows` 填充下拉 → 打开/关闭弹框 → 提交 analyze。要点：
- `pcAnalyzeInfo` 用 **`textContent` 纯文本**（勿 escapeHtml），信息行不含 HTML；
- **先 `var rec = pcAnalyzeRec` 捕获、`closeAnalyze()` 置空后再用**，避免 then 里读 null；
- 成功后 `refresh()`（非乐观，以后端为准，5s 轮询兜底）；失败保持弹框开启可换流程重试，不关框。

```js
function openAnalyze(rec) {
    pcAnalyzeRec = rec;
    var info = getEl('pcAnalyzeInfo');
    if (info) info.textContent = 'Start an agent workflow analysis for problem ' + (rec && rec.record_id ? rec.record_id : '') + '?';
    var sel = getEl('pcWorkflow');
    if (sel) sel.value = '';
    var overlay = getEl('pcAnalyzeOverlay');
    if (overlay) overlay.classList.add('open');
    if (pcWorkflows.length) fillAnalyzeWorkflows();
    else loadAnalyzeWorkflows();
}

function confirmAnalyze() {
    var rec = pcAnalyzeRec;
    if (!rec || analyzeBusy) return;
    var sel = getEl('pcWorkflow');
    var workflowId = sel ? sel.value : '';
    if (!workflowId) { window._showToast('请先选择已保存流程', 'error'); return; }
    analyzeBusy = true;
    var confirmBtn = getEl('pcAnalyzeConfirm');
    if (confirmBtn) confirmBtn.disabled = true;
    var recordId = rec.record_id; // 先捕获，closeAnalyze() 会置空 pcAnalyzeRec
    apmApi('/v1/problems/' + encodeURIComponent(recordId) + '/analyze', { method: 'POST', body: { workflow_id: workflowId } })
        .then(function () {
            analyzeBusy = false;
            if (confirmBtn) confirmBtn.disabled = false;
            closeAnalyze();
            window._showToast('Analyze started for ' + recordId, 'success');
            refresh(); // 非乐观，以后端为准（5s 轮询兜底）
        })
        .catch(function (err) {
            analyzeBusy = false;
            if (confirmBtn) confirmBtn.disabled = false;
            window._showToast('Analyze failed: ' + err.message, 'error'); // 保持弹框开启，可换流程重试
        });
}
```

`apmApi()`（app.js:3629，统一带 `X-Tenant-Id`/Bearer）指向 anomaly-detector :7070，analyze 出站到 agentflow
由后端 `bug_solve_base_url` 决定——前端无需直连 agentflow 发起 run。

### 5. `js/app.js` — 弹框生命周期接线 (app.js:4125-4138)

**原因**: 关闭按钮 / Cancel / Confirm / 点遮罩 / Escape 需与既有 `pcDetailOverlay` 一致的关闭模式；
Escape 合并进同一个 keydown（analyze 优先，其次 detail），互不抢占。

```js
// Analyze 弹窗生命周期（pcAnalyzeOverlay）：关闭按钮 / Cancel / Confirm / 点遮罩 / Escape
var pcAnalyzeClose = getEl('pcAnalyzeClose');
if (pcAnalyzeClose) pcAnalyzeClose.addEventListener('click', closeAnalyze);
var pcAnalyzeCancel = getEl('pcAnalyzeCancel');
if (pcAnalyzeCancel) pcAnalyzeCancel.addEventListener('click', closeAnalyze);
var pcAnalyzeConfirm = getEl('pcAnalyzeConfirm');
if (pcAnalyzeConfirm) pcAnalyzeConfirm.addEventListener('click', confirmAnalyze);
var pcAnalyzeOverlay = getEl('pcAnalyzeOverlay');
if (pcAnalyzeOverlay) pcAnalyzeOverlay.addEventListener('click', function (e) {
    if (e.target === this) closeAnalyze();
});
document.addEventListener('keydown', function (e) {
    if (e.key !== 'Escape') return;
    if (getEl('pcAnalyzeOverlay') && getEl('pcAnalyzeOverlay').classList.contains('open')) closeAnalyze();
    else if (getEl('pcDetailOverlay') && getEl('pcDetailOverlay').classList.contains('open')) closeProblemDetail();
});
```

## 影响范围

| 场景 | 预期 | 实际 | 状态 |

| 后端 analyze 失败（如 agentflow 停、重复触发 409） | 弹框保持可换流程重试，toast 报错 | `apmApi` reject → catch 分支不关框 | OK |

| Escape / 点遮罩 / Cancel / × | 关闭弹框且不影响列表 | `closeAnalyze()` | OK |
