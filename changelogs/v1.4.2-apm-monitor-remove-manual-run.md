# v1.4.2 — Monitor Targets 移除 Manual Run（暂下线，后续可加回）

**日期**: 2026-08-27

**问题/背景**: 模态框内原有的 **Manual Run**（手动触发一轮检测，`POST /v1/monitors/{id}/run`）在现阶段业务上暂不需要，先移除按钮与相关逻辑；后端接口保留，README 记录「后续菜单/流程有需要时可重新加回」。

---

## 改动明细

### 1. `index.html` — 弹窗操作区移除 Manual Run 按钮与说明 (line 1292-1296、1298)

**原因**: `apm-form-actions` 中删除 `#apmRunBtn`（Manual Run）及其说明文案（L3 持续性 2 轮提示）；结果区标题 `Test / Run Result` 同步改为 `Test Result`（Run 已移除，避免误导）。

```html
<!-- before -->
<div class="apm-form-actions">
    <button class="btn btn-primary" id="apmSaveBtn">Save</button>
    <button class="btn btn-secondary" id="apmTestBtn">Connectivity Test</button>
    <button class="btn btn-secondary" id="apmRunBtn">Manual Run</button>
    <button class="btn btn-outline" id="apmResetBtn">Reset</button>
    <span class="text-secondary text-xs apm-form-note">Manual Run 第 1 轮通常不开单（L3 持续性默认 2 轮）——再点一次 Run 看是否落 record。</span>
</div>
<!-- after -->
<div class="apm-form-actions">
    <button class="btn btn-primary" id="apmSaveBtn">Save</button>
    <button class="btn btn-secondary" id="apmTestBtn">Connectivity Test</button>
    <button class="btn btn-outline" id="apmResetBtn">Reset</button>
</div>
```

### 2. `js/app.js` — 移除 `manualRun()`、列表行 Run、run 分支与事件绑定 (line 3859-3880、3923-3925、3945-3951、3976-3978)

**原因**: 整段 Manual Run 功能下线——删除 `manualRun()` 函数（原在 `connectivityTest()` 与 `// ── List ──` 之间，调 `/v1/monitors/{id}/run`）；列表行删除 `data-act="run"` 按钮；`onListAction` 删除 `act === 'run'` 分支；事件绑定删除 `getEl('apmRunBtn').addEventListener('click', manualRun)`。`requireLoaded()` / `connectivityTest()` 仍被 Test 复用，不受影响。

```js
// before
} else if (act === 'run') { openModal(); fillForm(t); manualRun(); }
getEl('apmRunBtn').addEventListener('click', manualRun);
// after —— 均删除
```

### 3. `README.md` — 记录 Manual Run 暂移除与恢复方法

**原因**: 按用户要求，在 README 记录该功能当前阶段暂不需要、已下线，并写明「后续菜单/流程需要时可重新加回」（恢复 `index.html` 按钮 + `js/app.js` 的 `manualRun()`/run 分支/事件绑定即可，后端接口未变）。

## 踩坑记录

- **移除需整链同步**：`#apmRunBtn` 的 `addEventListener` 若保留，`getEl('apmRunBtn')` 返回 null 会在 `initMonitorTargets()` 里抛错；列表行 `data-act="run"` 若保留会触发已删除的 `manualRun()`（ReferenceError）。故按钮、函数、分支、事件绑定四者必须一起删。已用 `grep manualRun|apmRunBtn|data-act="run"|act === 'run'` 全 JS/HTML 扫描清零，`node --check` 通过。
- **结果区标题一致性**：`Test / Run Result` 改 `Test Result`，避免残留 "Run" 字样。
