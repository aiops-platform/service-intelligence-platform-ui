# v1.2.1 — Reflow Log 统计卡片改用 KPI 卡片样式

**日期**: 2026-07-06

**问题/背景**: Knowledge Reflow Log 页面的统计卡片风格与 Service Ops KPI 卡片不一致，且用户不需要图标。

---

## 改动明细

### 1. `index.html` — 统计卡片改用 `.kpi-card` 结构 (line 448-471)

**原因**: 去掉图标，复用 KPI 卡片样式保持设计一致性

```html
<!-- before -->
<div class="reflow-stat-card">
    <div class="reflow-stat-info">
        <h4>Total Reflowed Yesterday</h4>
        <div class="reflow-stat-value">47</div>
    </div>
    <div class="reflow-stat-icon bg-blue">&#8635;</div>
</div>

<!-- after -->
<div class="kpi-card">
    <div class="kpi-header">
        <span>Total Reflowed Yesterday</span>
    </div>
    <div>
        <div class="kpi-value">47</div>
        <div class="kpi-sub">knowledge entries processed in last 24h</div>
    </div>
</div>
```

三张卡片：
- Total Reflowed Yesterday: 47（蓝色）
- ServiceNow: 28（绿色 `#10b981`）
- Jira: 19（蓝色 `#3b82f6`）

每张卡片增加一行描述副标题。

### 2. `css/styles.css` — 简化 reflow stats 样式

**原因**: 移除旧的 `.reflow-stat-card` 等专用样式，直接复用 `.kpi-card`

```css
/* before */ 7 个独立 class
/* after */
.reflow-stats {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 16px;
    margin-bottom: 16px;
}
.reflow-stats .kpi-card {
    height: auto;
    min-height: 100px;
}
```
