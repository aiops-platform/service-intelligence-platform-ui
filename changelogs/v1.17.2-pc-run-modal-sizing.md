# v1.17.2 — style: 一级 View analysis 放大加宽；Flow Diagram 二级弹框缩小并嵌于一级框内

**日期**: 2026-09-07

**问题/背景**: v1.17.0 主弹框 920px 偏窄（左执行流程/右输入输出信息密度高），而 Flow Diagram 二级弹框反而做到 1200px，
比一级还宽，视觉层级反了。经确认：**一级弹框放大加宽，二级弹框缩小、不超过一级弹框**。

**方案**: 纯 CSS（`css/styles.css`），只调两个弹框的作用域尺寸与二级遮罩浓度，不动 DOM/JS。

---

## 改动明细

### `css/styles.css`
- 一级 `#pcRunOverlay`：
  - `.ap-modal` 由 `max-width:920px / calc(100vh - 120px)` → `max-width:1280px / calc(100vh - 88px)`；
  - 遮罩 padding 由 `60px 24px` → `40px 28px`，给更大弹框让位。
- 二级 `#pcRunGraphOverlay`：
  - `.ap-modal` 由 `max-width:1200px / calc(100vh - 80px)` → `max-width:960px`（**小于一级 1280**）、
    `height:calc(100vh - 200px); max-height:680px`；
  - 遮罩由默认 `rgba(0,0,0,.45)` 改为淡 scrim `rgba(15,23,42,.22)`，一级框仍隐约可见，体现"二级嵌于一级"的层级；
    点遮罩/Esc/× 收起行为不变。

---

## 影响范围

| 场景 | 预期 | 实际 | 状态 |
|------|------|------|------|
| View analysis | 一级弹框明显更大更宽（~1280），左右两栏更舒展 | `#pcRunOverlay .ap-modal` 1280/高放大 | OK |
| Flow Diagram | 二级比一级小（960 < 1280）、更高受控（≤680） | `#pcRunGraphOverlay .ap-modal` 缩尺寸 | OK |
| 二级打开时 | 淡 scrim，一级框隐约可见（嵌于一级） | overlay background 调淡 | OK |
| 关闭/Esc | 行为不变 | 接线未动 | OK |

- 纯样式改动，`node --check` 不涉 JS；建议浏览器走查两弹框比例与画布自适应（fitGraph 按框尺寸适配，缩框自动收敛）。
