# v2.2.0 — Ticket Inbox：点开看工单内容与运行情况

**日期**: 2026-09-16

**需求背景**: 列表只能看到一行摘要，点不进去。要知道这条工单到底报了什么、窗口是
哪一段、跑过几个 run、跑到哪一步了，此前只能去 Run 详情页反查——而 Run 详情只认
run_id，从工单过去还得先知道 run_id 是哪个。

---

## 改动明细

### 1. 整行可点 → 打开详情

`src/views/tickets/TicketsView.vue` 的表格行加 `@click="openDetail(t)"`。

**行内两个按钮一律 `@click.stop`**（「N runs」与「发起诊断」）——不加的话点按钮会连带
把详情弹窗也打开，两个动作叠在一起。

行的可点性靠 `cursor: pointer` + hover 底色提示；当前查看的那行有 `.active` 底色，
关闭弹窗后能看出刚才看的是哪条。

### 2. 详情弹窗：内容 + 运行情况

`useTickets.js` 新增 `openDetail` / `closeDetail` / `rerunFromDetail` 与三个展示 helper。

**先用行数据打底再拉全量**：列表里的对象本就有 `title`/`service`/`inputs`，弹窗能立刻
有内容而不是先空一下；`GET /tickets/{id}` 回来后再替换（状态可能是新的）。

**并发切换要丢弃过期结果**：拉取期间用户可能点了别的工单，回来时比对 `id`，
不是同一条就丢弃——否则会把 A 的详情贴到 B 上。

**单个 run 取不到不该让整个详情打不开**：`runApi.get()` 挂了就 `catch(() => null)` 跳过。
run 被清理、跨租户取不到都是正常的，不是"详情加载失败"。

#### 内容区

工单号 / 标题 / 服务 / namespace / severity / 创建时间 / 诊断窗口 / `bug_report` 原文。

#### 运行情况区

每个 run 一行：workflow 名、状态徽章、节点状态分布、耗时、待审批数。整块可点进
Run 详情（`/runs/{runId}`）。

**节点状态如实分组，不做解释性归类。** 后端在用的取值有 `done` / `skipped` /
`rejected` / `rejected-canceled`，将来还会加。把它们硬映射成"成功/失败/其它"会在
加新状态时变成一句谎话；直接列 `done 14 · skipped 1 · rejected-canceled 1` 永远是准的。

`ACTIVE_NODE_STATUSES`（`running`/`pending`/`waiting_approval`）**只用来标注"进行中"，
不用来判"已了结"**——判据单边定义，错也只错在少标一个"运行中"，不会把没跑完的说成跑完了。

### 3. 时间窗的时区告警（**顺手补的，不在原始需求里**）

详情页显示诊断窗口时，检查它**是否自描述**（带 `Z` 或 `±HH:MM`）：

```
2026-09-14T17:10:00+08:00   ✓ 正常
2026-09-14T17:00            ⚠ 会被按 UTC 解释
```

不带偏移的串会被 MCP server 按 **UTC** 解释，而人填的是本地时间 → 窗口整体错 8 小时，
**查询静默返回空**。`useTickets.js` 文件头用整段注释记录了这个坑，建单侧已修
（`toIsoWithOffset`），但**修复之前建的工单仍然躺在库里**。

实测当前 5 条工单里 **3 条**是 naive 的。详情页标出来，比事后翻库强。

> 觉得多余可以直接去掉 `windowWarning` 那一处渲染。

### 4. `css/styles.css` — 新增 `ticket-*` 段

原来这个视图是"全部复用既有样式、不新增"。详情弹窗引入了新结构，所以补了一小段。
另外补了 4 个状态徽章配色（`success` / `failed` / `canceled` / `waiting_approval`）——
后端 `_RUN_STATUS_TO_API = {"done": "success"}`，**run 的状态是 `success` 而不是 `done`**，
既有的 `.status-done` 落不到它身上。

## 已知取舍

- 详情用弹窗而不是路由（`/tickets/:id`）。理由是与既有 New Ticket 模态同构，
  且工单详情不需要可分享的 URL。若将来要深链再改路由。
- run 快照是**打开时取一次**，不含轮询。跑着的 run 要看实时进度请点进 Run 详情
  （那页本来就有轮询）。
