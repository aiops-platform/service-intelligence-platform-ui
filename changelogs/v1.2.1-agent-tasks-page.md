# v1.2.1 — Agent Tasks 页面

**日期**: 2026-07-07

**问题/背景**: Business Ops > Ticket Workspace > Agent Tasks 需要独立详情页，展示 Agent 任务的统计、列表和详情抽屉，参考 `knowledge/deepseek_html_20260707_6b205d.html` 设计，风格需符合 SIP 设计系统。

---

## 改动明细

### 1. `index.html` — 新增 `#page-agent-tasks` 页面面板

**原因**: 添加 Agent Tasks 的完整页面结构

页面组成：
- 面包屑导航：Business Ops › Ticket Workspace › **Agent Tasks**
- 4 个 KPI 统计卡片（Total Tasks / Avg Confidence / Pending Approval / Total Tokens）
- 搜索工具栏 + 状态筛选芯片（All / Running / Pending / Done）
- 8 列表格（Agent Task ID / Task Description / Status / Confidence / Risk / Tokens / Trigger Time / 操作列）
- 分页信息栏

### 2. `css/styles.css` — Agent Tasks 专属样式

**原因**: 新增 Agent Tasks 特有的 UI 组件样式

新增样式：
- `.agent-status` — 状态胶囊标签（running 蓝 / approval 黄 / done 绿）
- `.agent-spin` — running 状态旋转动画指示器
- `.confidence-bar` / `.conf-bar-track` / `.conf-bar-fill` — 置信度进度条（high/medium/low 三档）
- `.risk-tag` — 风险等级标签（low 绿 / medium 黄 / high 红）
- `.token-number` — Token 数量高亮样式
- Drawer 内执行日志、诊断结论、审批按钮样式

### 3. `js/app.js` — 新增 `initAgentTasks()` 函数 + 接入 init()

**原因**: 实现 Agent Tasks 页面的完整交互逻辑

`initAgentTasks()`：
- 6 条 mock Agent 任务数据（覆盖 running / pending_approval / done 三种状态）
- `renderAgentTable()` — 渲染任务表格，包括状态标签、置信度进度条、风险标签
- `renderAgentDetail(taskId)` — 渲染右侧详情抽屉，展示执行时间线 + 诊断结论 + 审批操作按钮
- 搜索过滤（按 Agent ID、Ticket、Service 模糊匹配）
- 状态筛选（All / Running / Pending / Done filter chips）
- 行点击打开详情抽屉

`init()` 中新增 `initAgentTasks()` 调用。

### 4. `initSidebar()` 路由更新

**原因**: sidebar 叶子节点点击时正确切换到 Agent Tasks 页面

点击 `agent-tasks` → `showPage('page-agent-tasks')`
点击 `approval-center` → 暂用 `showPage('page-agent-tasks')` 占位
