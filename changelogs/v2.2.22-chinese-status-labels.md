# v2.2.22 — 节点状态名 `rejected-canceled` → 「审批超时」；状态文案统一中文

**日期**: 2026-09-21

**需求/背景**: 用户要求两件事 ——
「把节点状态名 `rejected-canceled` 也改成审批超时。在 ticket detail 的列表中的状态统一使用中文描述。」

---

## 改动明细

### 1. `src/utils/runStatus.js` — 新增 `STATUS_LABELS` / `statusLabel` / `nodeStatusLabel` / `runStatusLabel`

**一张表收口**。同一个状态会在四个地方露出文字：工单列表列、工单详情的 run 行、
详情的节点分布、Run 详情的节点表。各写一份的结果是同一个状态在不同页面叫不同名字
—— 本轮已经因为"判定分散"踩过一次（图是绿的、表写 done、徽章说中断）。

```js
export const STATUS_LABELS = {
  success: '成功', failed: '失败', cancelled: '已取消', running: '进行中',
  queued: '排队中', paused: '已暂停', completed: '已完成',
  new: '新建', resolved: '已解决',
  halted: '中断', rejected: '审批不通过', needs_info: '缺少必要信息',
  waiting_approval: '待审批',
  done: '完成', pending: '等待中', skipped: '已跳过',
  'rejected-canceled': '审批超时',          // ← 本次的重点
}
```

两条约定：

1. **表里没有的原样透出**（`statusLabel` 的兜底）。后端加新状态时界面显示那串英文
   原名，而**不是**悄悄显示成空白或"其它"—— 宁可难看，也不要让人以为看懂了。
2. `rejected` 与 `rejected-canceled` **必须分开**：前者是**人明确驳回**，
   后者是**超时自动拒绝**（没人来处理）。后续动作完全不同。

`runStatusLabel(run)` 比 `statusLabel` 多一件事：`rejected` 要看 `reject_reason`
才能定文案（`timeout` → 审批超时 / 其它 → 审批不通过）。

### 2. ticket 区（`useTickets.js` / `TicketsView.vue`）

- 筛选 chip 全部中文：全部 / 新建 / 进行中 / 待审批 / 审批不通过 / 需要补充信息 /
  已解决 / 失败
- 详情弹窗的 **run 行**用 `runStatusLabel(r)`（原先直接显示 `success` 等英文）
- 详情弹窗的**节点分布**用 `statusLabel(s)`，并把后端原名放进 `title`
  （鼠标悬停仍能查到 `rejected-canceled` 之类的原值）

### 3. Run 详情 / Bug Solve / 悬停提示

- `RunDetailView.vue`：run 徽章、节点表、节点详情徽章
- `BugSolveView.vue`：`bsStatus`、节点详情 `bs-badge`
- `components/graph/nodeTip.js`：悬停提示的 `status` 一行

> **范围说明**：用户只点名了 ticket detail，但 `rejected-canceled` → 审批超时 是个
> **重命名**，重命名需要一个一致的目标 —— 只在工单详情改、Run 详情不改，
> 会变成同一个节点在两个页面叫两个名字。所以节点状态名**全局**中文，
> run 级文案在 Run 详情也一并中文（否则同一张节点表里"完成/已跳过"与
> "success" 混排）。全部集中在 `STATUS_LABELS` 一张表，要回退只改它。

## 踩坑记录（本次自己踩的）

第一版 `ticketStatusLabel` 写成了「有 run 就甩给 `runStatusLabel`」：

```js
if (r) return runStatusLabel(r)   // ✗
```

后果：列表里 6 条「缺少必要信息」**一起变成了「中断」**。

因为同一件事在两级叫法不同 —— run 说**中断**（技术视角，停在 halt 节点），
工单说**缺少必要信息**（业务视角，等人补服务名 / trace_id）。
**工单的文案必须从工单自己的展示状态出发**，只有"否决要看理由"那一个分支才需要 run。
