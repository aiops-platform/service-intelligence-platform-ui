# v1.11.1 — MCP Server 配置页改造：Monitor Targets 风格 + 弹窗编辑，去掉 Bind Agents

**日期**: 2026-09-03

**问题/背景**: v1.11.0 的 MCP Server 配置页（`#page-mcp-servers`）是「左：内联配置表单 + 已保存列表 / 右：Tools 结果栏」的两栏布局，页面内还含一段 **Bind Agents**（勾选绑定 agent）编辑 UI。用户要求：
1. 页面风格改成 **Monitor Targets** 那样：顶部是已配置 MCP Server 的**列表**，点 **New** 弹出**弹窗**录入/编辑 server 信息（含测试连接）。
2. **去掉 Bind Agents**。经确认：后续 agent 绑定将以 **agent 为主表**建模，MCP server 不再是绑定主表；本页不再按 server 勾选 agent，更新保存时也不再保留该列绑定语义。

> 纯前端改动（`index.html` / `js/app.js` / `css/styles.css`），后端 `multi-agent-workflow` 未动。计划稿另存档于 `docs/v1.11.1-mcp-server-config-monitor-style-plan.md`。

---

## 改动明细

### 1. `index.html` — MCP 页整段改为 Monitor Targets 风格 + 紧随弹窗 (index.html:1553)

**原因**: 两栏内联布局 + Bind Agents 改为「列表 + New 弹窗」。整段替换旧 `#page-mcp-servers`（旧约 L1552–1662），删掉 Bind Agents 整块与旧 `#mcpAgents` 容器；保留全部既有字段 id。

**列表页 `#page-mcp-servers`**（index.html:1553–1595）：
- breadcrumb / 标题 / 右上 Refresh 保留；副文案去掉 "bind to agents" 措辞（改为 "configure a generic MCP server (stdio / HTTP) → MCP tools coexist with built-in function tools"）。
- `reflow-filter-bar`：搜索框 `#mcpSearch`（按 name/transport 过滤）+ 右侧 `#mcpNewBtn`（btn-primary）。
- `#mcpTableContainer` + 加载遮罩 `#mcpLoadingOverlay` + `table.reflow-table`：列 = **Server Name | Transport | Tools | Enabled | Created | Actions**；`<tbody id="mcpTableBody">`（行内 Edit / Test / Delete）。
- 底部 pagination 行：`Total N servers` + 提示 "Edit / Test / Delete"。

**弹窗 `#mcpModalOverlay`**（index.html:1598 起，Monitor Target modal 同款 `.ap-modal-overlay/.ap-modal`）：
- Header：`#mcpFormTitle`（"MCP Server Form"）+ `#mcpFormHint`（New Server / Editing {name}）+ 关闭 `#mcpModalClose`。
- 字段：`#mcpName` *（含 `mcp__{name}__` 前缀提示）、`#mcpTransport` *（stdio/http）、
  `#mcpFieldsStdio`（`#mcpStdioCommand` * / `#mcpStdioArgs` 每行一个 / `#mcpStdioCwd`）、
  `#mcpFieldsHttp`（`#mcpHttpUrl` * / `#mcpHttpHeaders` JSON / `#mcpHttpStateful` 勾选）、
  Options：`#mcpEnabled` 勾选 + `#mcpEnableTools` / `#mcpDisableTools`（白/黑名单逗号分隔）。
- `#mcpError`（顶部红条，隐藏默认）+ `details#mcpResult`「测试连接 · Tools 探测」结果区（`#mcpResultMeta` + `#mcpResultBody`）。
- 按钮 `apm-form-actions`：Save Server(primary) / 测试连接(secondary) / Reset(outline)。
- 关闭：× / 点遮罩 / Esc；transport 切换联动 stdio/http 卡片显隐并清空上次探测结果。

### 2. `js/app.js` — 重写 `initMcpServers()` 为「弹窗 + 表格」版 (app.js:5993)

**原因**: 列表+New 弹窗交互，去掉 server 主表 agent 绑定逻辑。移除 `AGENTS_API_BASE`/`agentNames`/`selectedAgents()`/`loadAgentOptions()`/`renderAgentOptions()` 及全部 `#mcpAgents` 代码（grep 确认零残留）。

- `MCP_API_BASE`（沿用 `mcpBaseUrl`→`workflowBaseUrl`→`http://localhost:8000`）+ `_showToast` + `escapeHtml` 复用既有约定。
- `renderList()`：行内 `data-id` + 列 name/transport/tools-badge/enabled-badge/created + `apm-row-btn` Edit/Test/Delete（委托在 `#mcpTableBody`，Monitor Targets 同款）。
- `loadServers()`：`GET /mcp-servers`（列表已含全量 config/tools）→ `renderList()`；loading overlay + 失败 `_showToast`；空态 `.mcp-table-empty`。
- `openModal/closeModal/setFormHint`；`renderTools(data,capture)` 写 `#mcpResultBody`（`.mcp-tools` 卡列 + `toolItemHtml`），`renderCachedTools(s)` 回填已存快照，`writeResultEmpty()`。
- `testConnection()`：读表单调 `POST /mcp-servers/test` → capture=true（成功即存 `currentTools`）渲染结果；失败 → `.mcp-result-error` 红条。
- `save()`：`buildBody()` **刻意不带 `agents`**（后端 `_to_row` 缺省 `[]` → 更新即清空旧绑定，符合 agent 主表方向）；返回 `{name, transport, config, is_stateful, enable_tools, disable_tools, tools: currentTools, enabled}`（tools=live 成功快照；create null→自动探测 / update null→保留已存快照）→ POST 201 / PUT → closeModal + loadServers + toast。
- `openNew()`：reset+打开；`openEdit(mid, probe)`：`findServer`（列表含 config/tools）→ 回填 + 显示已存快照 → openModal（probe=true 再走 `GET /mcp-servers/{mid}/tools` 实时刷新）。
- `liveProbe(mid)`：`GET /mcp-servers/{mid}/tools` → 列表 tools 徽标刷新。
- `remove(mid)`：`window.confirm` → `DELETE /mcp-servers/{mid}`。
- `bindEvents()`：transport change→`setTransportUi()+resetToolsArea()`；save/test/reset/new/refresh；`#mcpSearch` 防抖过滤；close/X/overlay/Esc。
- `_pageRefreshers['page-mcp-servers'] = loadServers`（app.js:6466）；`init()` 中 `initMcpServers()` 调用不变（app.js:6491）。路由映射沿用 v1.11.0 的 `mcp-servers` → `page-mcp-servers`（页面 id 未变，无需改）。

### 3. `css/styles.css` — MCP 区块替换为弹窗/列表样式 (styles.css:5674)

**原因**: 清理两栏 + agent chips 旧布局，补 Monitor modal 尺寸与列表/工具卡间距。

- **删除失效布局**：`.mcp-body/.mcp-panel/.mcp-fields/.mcp-agents/.mcp-agent-chip/.mcp-actions/.mcp-list-title/.mcp-list*/.mcp-meta-badges/.mcp-agent-badge/.mcp-btn*/.mcp-result-head/.mcp-tool-...` 旧两栏相关（grep 确认零残留）。
- **保留**：`.mcp-error/.mcp-hint/.mcp-check/.mcp-inline/.mcp-result-error` 与工具卡 `.mcp-tool-item/.mcp-tool-head/.mcp-tool-name/.mcp-ro-badge(.mcp-ro-allow/.mcp-ro-deny)/.mcp-tool-llm/.mcp-tool-desc`。
- **新增**：`#mcpModalOverlay .ap-modal`（宽 820px、`height: calc(100vh - 120px)` 内滚动，参考 `#dcModalOverlay/#apmModalOverlay` 写法）；`.mcp-form/.mcp-config/.mcp-config-title/.mcp-tools`；`.mcp-server-name`（名字单元格 mono）；`.mcp-table-empty`（空态）。
- **复用全局**：`reflow-filter-bar/reflow-table/table-container/si-loading-overlay/si-loading-spinner/pagination/ap-modal* /apm-field/apm-req/apm-hint/apm-form-actions/apm-result/apm-row-btn/apm-row-del/text-secondary/btn(-primary/-secondary/-outline)`（Monitor Targets / Domain Config 同套既有惯例）。
